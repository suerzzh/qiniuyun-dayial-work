06

SYSTEM ARCHITECTURE / 04

SessionService 统一管理对话会话的
完整生命周期

SESSION LIFECYCLE

01 / STARTstartSession()

根据场景类型与 Prompt 创建业务会话，返回 sessionId 与开始时间。

02 / APPENDaddMessage()

只保存用户或 AI 的完整消息；先内存追加，再异步持久化。

03 / ENDendSession()

记录结束时间，为学习报告、资产与复练提供完整上下文。

FreeChatSessionService

自由聊天 Prompt 与消息；结束后更新长期记忆。

CustomSessionService

场景 Prompt 与任务上下文；结束后生成报告并完成流程。

职责边界

Realtime SDP 属于 AiProviderService；单轮评分属于 EvaluationService。

07

SYSTEM ARCHITECTURE / 05

EvaluationService 将音频、字幕和上下文，
合成可解释的学习结果

THREE EVALUATION LEVELS

LEARN跟读评分

evaluateSentence() 返回总分，页面直接展示并控制句子阶段通过。

DIALOGUE单轮评价

保存流利度、发音、节奏、语调、语法、词汇与相关性，不直接打断用户。

REPORT最终报告

汇总整场对话各轮证据，生成五维、可复练的学习报告。

FiveDimensionScore

结果只在完整对话结束后面向用户呈现。

01发音
02流利度
03语法
04词汇
05沟通
