# 自定义场景 Realtime 状态机架构与伪代码

本文档描述 `scenario-engine-demo` 当前已经验证的实现。Demo 使用真实 Qwen 模型生成场景、进行实时语音对话和语义事件抽取，不使用固定话术或关键词规则。

## 一、整体架构

```text
自定义场景实时状态机流程

LiveScenarioService
├── 作用：编排场景生成、会话管理、字幕落盘、语义抽取和状态迁移
├── create(topic) -> ScenarioSession
│   └── 根据用户自定义话题生成场景定义并创建本地会话
├── get(sessionId) -> ScenarioSession
│   └── 获取状态机快照、槽位、对话、事件和控制指令
├── acceptTranscript(sessionId, speaker, transcript) -> ScenarioSession
│   ├── USER 字幕：保存后进入串行异步语义抽取队列
│   └── AI 字幕：只保存为上下文，不触发语义抽取
├── reset(sessionId) -> ScenarioSession
│   └── 使用原自定义话题重新生成场景并创建新会话
└── close(sessionId) -> ScenarioSession
    └── 在 COMPLETED 后应用 AI_CLOSED，使状态进入 CLOSING
│
├── QwenScenarioGenerator
│   ├── 作用：使用真实大模型将任意话题转换为可运行的场景定义
│   └── generate(topic) -> ScenarioDefinition
│       ├── 生成 goal、aiRole、userRole、requiredSlots 和 maxTurns
│       ├── 生成供 Omni-Realtime 使用的 realtimeInstruction
│       ├── 删除 confirmation、closing 等非业务槽位
│       └── 点单/购买场景缺少尺寸或数量时补充 size_or_quantity
│
├── QwenEventExtractor
│   ├── 作用：结合上下文，将用户最终字幕抽取成结构化语义事件
│   └── extract(session, speaker, transcript) -> ScenarioEvent
│       ├── 输入场景定义、当前状态、已有槽位和最近 16 轮对话
│       ├── 输出 ORDER_UPDATE、CORRECTION、USER_CONFIRMED 等事件
│       └── 输出 correctedTranscript，对 ASR 做高置信最小纠错
│
├── ScenarioSession
│   ├── 作用：保存单次场景会话的数据，并执行确定性状态迁移
│   ├── addTurn(speaker, transcript) -> turnNumber
│   ├── correctTurn(turnNumber, correctedTranscript) -> void
│   ├── apply(event) -> void
│   ├── hasAllRequiredSlots() -> boolean
│   └── 维护 stage、status、order、conversation、events 和 controlInstructions
│
├── RealtimeBackendProxy
│   ├── 作用：复用昨天的 Realtime 后端完成 WebRTC SDP 交换
│   └── connect(request) -> answerSdp
│       └── 转发到 unispeaking-server /api/scene-sessions
│
└── BrowserRealtimeClient
    ├── 作用：管理麦克风、WebRTC、DataChannel、流式字幕和自然结束
    ├── startCall(topic) -> void
    ├── handleProviderMessage(event) -> void
    ├── forwardTranscript(speaker, transcript) -> void
    ├── pollState() -> void
    ├── armNaturalClose() -> void
    └── finalizeNaturalClose() -> void
```

## 二、模型职责划分

```text
QwenScenarioGenerator
负责把用户的任意话题变成动态场景定义

Qwen Omni-Realtime
负责真实语音识别、角色扮演、实时语音回复和增量字幕

QwenEventExtractor
负责理解用户最终表达、修正上下文相关的 ASR 错词并生成状态机事件

ScenarioSession
负责确定性判断槽位是否完整、是否允许完成以及何时关闭
```

核心原则：大模型负责“理解”，状态机负责“决定”。模型不能直接将会话标记为完成；只有 `ScenarioSession` 校验所有必填槽位后，才能进入 `COMPLETED`。

## 三、两条并行链路

```text
实时语音链路（低延迟）

浏览器麦克风
→ WebRTC
→ 昨天的 Realtime 后端
→ Qwen Omni-Realtime
→ AI 音频直接返回浏览器播放


语义状态链路（异步）

Realtime 用户转写 delta
→ 浏览器流式显示 USER 字幕
→ Realtime 用户转写 completed
→ LiveScenarioService.acceptTranscript
→ QwenEventExtractor.extract
→ ScenarioSession.correctTurn/apply
→ 浏览器轮询最新状态
→ 必要时发送 session.update 控制 Realtime 模型
```

AI 语音回复不等待状态抽取，所以语音交互延迟不会被语义模型阻塞。语义抽取只处理已经完成的用户字幕，并在同一会话内串行执行，避免连续说话导致事件乱序。

## 四、核心数据结构

```java
enum ScenarioStage {
    START,
    GREETING,
    COLLECTING_INFORMATION,
    CONFIRMATION,
    COMPLETED,
    CLOSING
}

enum EventType {
    GREETING_STARTED,
    ORDER_UPDATE,
    CORRECTION,
    USER_CONFIRMED,
    AI_CLOSED,
    UNEXPECTED_REQUEST,
    TRANSCRIPT_CORRECTED
}

record ScenarioDefinition(
    String topic,
    String goal,
    String aiRole,
    String userRole,
    Map<String, String> requiredSlots,
    int maxTurns,
    String realtimeInstruction
) {}

record ScenarioEvent(
    EventType type,
    Map<String, String> values,
    Map<String, String> previousValues,
    double confidence,
    String correctedTranscript,
    Instant occurredAt
) {}

class ScenarioSession {
    String id;
    ScenarioDefinition definition;
    ScenarioStage stage = GREETING;
    String status = "waiting_for_conversation";

    Map<String, String> order;
    List<ConversationTurn> conversation;
    List<ScenarioEvent> events;
    List<ControlInstruction> controlInstructions;

    int revision;
    int processingEvents;
    String lastError;
}
```

说明：`START` 是前端创建会话之前的逻辑状态；后端 `ScenarioSession` 创建成功后从 `GREETING` 开始。

## 五、状态迁移规则

```text
START
└── 场景生成成功、Realtime 建连
    └── GREETING
        └── ORDER_UPDATE
            └── COLLECTING_INFORMATION
                ├── 仍有缺失槽位
                │   └── 保持 COLLECTING_INFORMATION，由 AI 继续追问
                └── 所有必填槽位完整
                    └── CONFIRMATION
                        ├── CORRECTION
                        │   ├── 修正后槽位完整 → CONFIRMATION
                        │   └── 修正后槽位缺失 → COLLECTING_INFORMATION
                        ├── USER_CONFIRMED，但槽位不完整
                        │   └── COLLECTING_INFORMATION
                        └── USER_CONFIRMED，且槽位完整
                            └── COMPLETED
                                ├── 生成一次 session.update
                                ├── 立即关闭本地麦克风
                                └── AI 最终告别完成
                                    └── AI_CLOSED
                                        └── CLOSING
```

状态事件对应关系：

| 当前状态 | 事件 | 守卫条件 | 下一状态 | 处理动作 |
|---|---|---|---|---|
| `GREETING` / `COLLECTING_INFORMATION` | `ORDER_UPDATE` | 仍有缺失槽位 | `COLLECTING_INFORMATION` | 合并新槽位 |
| `GREETING` / `COLLECTING_INFORMATION` | `ORDER_UPDATE` | 所有槽位完整 | `CONFIRMATION` | 合并新槽位，等待最终确认 |
| 任意业务状态 | `CORRECTION` | 修正后仍缺槽位 | `COLLECTING_INFORMATION` | 覆盖旧值，修订次数加一 |
| 任意业务状态 | `CORRECTION` | 修正后槽位完整 | `CONFIRMATION` | 覆盖旧值并重新确认 |
| `CONFIRMATION` 或抽取滞后的业务状态 | `USER_CONFIRMED` | 所有槽位完整 | `COMPLETED` | 只生成一次自然结束指令 |
| 任意未完成状态 | `USER_CONFIRMED` | 存在缺失槽位 | `COLLECTING_INFORMATION` | 拒绝提前完成 |
| `COMPLETED` | `AI_CLOSED` | AI 最终回复结束 | `CLOSING` | 关闭连接并清理媒体资源 |
| 非 `COMPLETED` | `AI_CLOSED` | AI 提前告别 | 状态不变 | 标记 `premature_closing_detected` |
| 任意状态 | `UNEXPECTED_REQUEST` | 无法归入业务事件 | 状态不变 | 标记 `needs_recovery` |
| 任意状态 | `TRANSCRIPT_CORRECTED` | 仅发生字幕纠错 | 状态不变 | 替换对应 USER 字幕 |

## 七、伪代码

### 7.1 根据自定义话题生成场景

```java
public ScenarioSession createScenario(
        String requestedTopic) {

    // =====================================================
    // 1. 规范化用户话题
    // =====================================================

    String topic = isBlank(requestedTopic)
        ? "Order coffee at a café"
        : requestedTopic.trim();


    // =====================================================
    // 2. 调用真实模型生成结构化场景
    // =====================================================

    ScenarioDefinition generated =
        QwenScenarioGenerator.generate(topic);

    // generated 包含：
    // - goal
    // - aiRole
    // - userRole
    // - requiredSlots
    // - maxTurns
    // - realtimeInstruction


    // =====================================================
    // 3. 清理不应作为业务目标的槽位
    // =====================================================

    generated.requiredSlots.removeIf(slot ->
        slot.isConfirmation()
        || slot.isFinalAgreement()
        || slot.isClosing()
    );


    // =====================================================
    // 4. 对点单/购买类场景做确定性保护
    // =====================================================

    if (isOrderingOrPurchasing(topic)
            && !generated.hasSizeOrQuantitySlot()) {

        generated.requiredSlots.put(
            "size_or_quantity",
            "用户明确说明适用的尺寸、份量或数量，不允许使用默认值"
        );
    }


    // =====================================================
    // 5. 把必达事项追加到 Realtime 指令
    // =====================================================

    generated.realtimeInstruction +=
        buildRequiredOutcomeInstruction(
            generated.requiredSlots
        );

    generated.realtimeInstruction +=
        "收齐所有事项后总结一次，并询问明确的最终确认；"
        + "用户确认后只说一句简短告别，不再提出新问题。";


    // =====================================================
    // 6. 创建状态机会话
    // =====================================================

    ScenarioSession session =
        new ScenarioSession(generated);

    session.stage = GREETING;
    session.status = "waiting_for_conversation";

    SessionStore.put(
        session.id,
        session
    );

    return session;
}
```

### 7.2 建立真实 Realtime 通话

```javascript
async function startCall(topic) {
    // =====================================================
    // 1. 先生成动态场景并取得 sessionId
    // =====================================================

    session = await POST(
        "/api/demo/sessions",
        { topic }
    );


    // =====================================================
    // 2. 获取本地麦克风
    // =====================================================

    localStream = await getUserMedia({
        audio: {
            echoCancellation: true,
            noiseSuppression: true,
            autoGainControl: true
        }
    });

    microphoneTrack =
        localStream.getAudioTracks()[0];

    // 配置完成前先不上传声音
    microphoneTrack.enabled = false;


    // =====================================================
    // 3. 创建 WebRTC 和 DataChannel
    // =====================================================

    peer = new RTCPeerConnection();
    audioSender = peer.addTrack(
        microphoneTrack,
        localStream
    );

    await audioSender.replaceTrack(null);

    channel = peer.createDataChannel(
        "oai-events"
    );

    channel.onmessage = event ->
        handleProviderMessage(event.data);


    // =====================================================
    // 4. 通过昨天的后端完成 SDP 交换
    // =====================================================

    offerSdp = await peer.createOffer();
    await peer.setLocalDescription(offerSdp);
    await waitForIceGatheringComplete();

    connectResult = await POST(
        "/api/realtime/connect",
        {
            userId: "scenario-demo-user",
            offerSdp: peer.localDescription.sdp,
            topic: session.definition.topic,
            provider: "QWEN",
            voice: "Katerina"
        }
    );

    await peer.setRemoteDescription({
        type: "answer",
        sdp: connectResult.answerSdp
    });

    await waitForDataChannelOpen();


    // =====================================================
    // 5. 定时同步状态机快照
    // =====================================================

    pollTimer = setInterval(
        pollState,
        700
    );
}
```

### 7.3 处理 Realtime 事件和流式字幕

```javascript
async function handleProviderMessage(rawEvent) {
    RealtimeEvent event = JSON.parse(rawEvent);


    // =====================================================
    // 1. Realtime 会话创建完成
    // =====================================================

    if (event.type == "session.created") {
        await audioSender.replaceTrack(
            microphoneTrack
        );

        microphoneTrack.enabled = !muted;

        sendProvider({
            type: "session.update",
            session: {
                modalities: ["text", "audio"],
                voice: "Katerina",
                instructions:
                    session.definition.realtimeInstruction,
                input_audio_transcription: {
                    model: "qwen3-asr-flash-realtime"
                },
                turn_detection: {
                    type: "server_vad"
                }
            }
        });

        return;
    }


    // =====================================================
    // 2. 配置成功后让 AI 主动开场
    // =====================================================

    if (event.type == "session.updated"
            && !configured) {

        configured = true;

        sendProvider({
            type: "response.create"
        });
    }


    // =====================================================
    // 3. 用户字幕增量到达，立即流式展示
    // =====================================================

    if (event.type ==
            "conversation.item.input_audio_transcription.delta") {

        streamingCaptions.USER +=
            event.delta;

        renderConversation();
    }


    // =====================================================
    // 4. 用户最终字幕到达，提交语义分析
    // =====================================================

    if (event.type ==
            "conversation.item.input_audio_transcription.completed") {

        streamingCaptions.USER =
            event.transcript;

        renderConversation();

        // 不阻塞 Realtime 音频链路
        async forwardTranscript(
            USER,
            event.transcript
        );
    }


    // =====================================================
    // 5. AI 字幕增量到达，立即流式展示
    // =====================================================

    if (event.type ==
            "response.audio_transcript.delta") {

        streamingCaptions.AI +=
            event.delta;

        renderConversation();
    }


    // =====================================================
    // 6. AI 最终字幕只保存为后续语义上下文
    // =====================================================

    if (event.type ==
            "response.audio_transcript.done") {

        streamingCaptions.AI =
            event.transcript;

        renderConversation();

        async forwardTranscript(
            AI,
            event.transcript
        );
    }


    // =====================================================
    // 7. 最终 AI 回复播放完成后断开连接
    // =====================================================

    if (event.type == "response.done") {
        assistantResponseActive = false;

        if (naturalCloseArmed) {
            scheduleFinalDisconnect(650);
        }
    }
}
```

### 7.4 串行异步抽取用户语义

```java
public ScenarioSession acceptTranscript(
        String sessionId,
        Speaker speaker,
        String transcript) {

    ScenarioSession session =
        SessionStore.get(sessionId);

    if (isBlank(transcript)) {
        return session;
    }


    // =====================================================
    // 1. 最终字幕先进入完整对话上下文
    // =====================================================

    int turnNumber;

    synchronized (session) {
        turnNumber = session.addTurn(
            speaker,
            transcript.trim()
        );

        // AI 字幕只作为下一轮用户抽取的上下文
        if (speaker == AI) {
            return session;
        }

        session.startProcessing();
    }


    // =====================================================
    // 2. 同一 session 的抽取任务串行连接
    // 防止用户连续说话造成事件乱序
    // =====================================================

    CompletableFuture previous =
        extractionChains.get(sessionId);

    CompletableFuture current =
        previous
            .recoverFromFailure()
            .thenRunAsync(() -> {
                extractAndApply(
                    session,
                    USER,
                    transcript.trim(),
                    turnNumber
                );
            });

    extractionChains.put(
        sessionId,
        current
    );

    return session;
}


private void extractAndApply(
        ScenarioSession session,
        Speaker speaker,
        String transcript,
        int turnNumber) {

    try {
        ScenarioEvent event =
            QwenEventExtractor.extract(
                session,
                speaker,
                transcript
            );

        synchronized (session) {
            if (event != null) {

                // 用上下文语义纠正最终字幕
                // 例如：Price. → Fries.
                session.correctTurn(
                    turnNumber,
                    event.correctedTranscript
                );

                // 状态迁移必须由确定性状态机执行
                session.apply(event);
            }

            session.finishProcessing();
        }
    } catch (Exception error) {
        synchronized (session) {
            session.failProcessing(
                error.getMessage()
            );
        }
    }
}
```

### 7.5 语义事件抽取和字幕纠错

```java
public ScenarioEvent extract(
        ScenarioSession session,
        Speaker speaker,
        String newestTranscript) {

    // =====================================================
    // 1. 组织上下文
    // =====================================================

    ExtractionContext context = new ExtractionContext(
        session.definition,
        session.stage,
        session.status,
        session.order,
        session.conversation.last(16),
        speaker,
        newestTranscript
    );


    // =====================================================
    // 2. 调用真实语义模型
    // =====================================================

    Json result = LlmService.generateJson(
        model = "qwen3.5-flash",
        temperature = 0,
        systemPrompt = EVENT_EXTRACTION_PROMPT,
        userInput = context
    );


    // =====================================================
    // 3. 解析结构化事件
    // =====================================================

    EventType type = parseEventType(
        result.type
    );

    String correctedTranscript =
        result.correctedTranscript;

    boolean transcriptChanged =
        isNotBlank(correctedTranscript)
        && !correctedTranscript.equals(
            newestTranscript
        );


    // =====================================================
    // 4. 普通填充词且没有字幕修正时忽略
    // =====================================================

    if (type == NONE
            && !transcriptChanged) {
        return null;
    }

    if (type == NONE
            && transcriptChanged) {
        type = TRANSCRIPT_CORRECTED;
    }

    return new ScenarioEvent(
        type,
        result.values,
        result.previousValues,
        result.confidence,
        correctedTranscript,
        now()
    );
}
```

字幕纠错遵循以下约束：

```text
只纠正最新一轮 USER 最终字幕
只做高置信、最小范围、语音相近的纠正
必须使用上一轮 AI 问题和最近对话作为依据
不修改用户语法，不美化表达，不创造用户没有说过的信息
增量字幕保持实时；最终语义结果返回后替换已经落下的最终字幕
```

### 7.6 执行确定性状态迁移

```java
public void apply(
        ScenarioEvent event) {

    events.add(event);

    switch (event.type) {

        case GREETING_STARTED:
            transitionTo(
                GREETING,
                "waiting_for_order"
            );
            break;


        case ORDER_UPDATE:
            // 合并用户新提供的业务信息
            order.putAll(event.values);

            if (hasAllRequiredSlots()) {
                transitionTo(
                    CONFIRMATION,
                    "pending_confirmation"
                );
            } else {
                transitionTo(
                    COLLECTING_INFORMATION,
                    "collecting_information"
                );
            }
            break;


        case CORRECTION:
            // 新值覆盖旧值
            order.putAll(event.values);
            revision++;

            if (hasAllRequiredSlots()) {
                transitionTo(
                    CONFIRMATION,
                    "pending_confirmation"
                );
            } else {
                transitionTo(
                    COLLECTING_INFORMATION,
                    "collecting_information"
                );
            }
            break;


        case USER_CONFIRMED:
            // 抽取器可以补充上下文中已经明确、
            // 但尚未来得及写入状态的槽位
            order.putAll(event.values);

            if (!hasAllRequiredSlots()) {
                transitionTo(
                    COLLECTING_INFORMATION,
                    "confirmation_rejected_missing_slots"
                );
                break;
            }

            transitionTo(
                COMPLETED,
                "completed"
            );

            // 幂等保护：自然结束指令只生成一次
            if (controlInstructions.isEmpty()) {
                controlInstructions.add(
                    ControlInstruction.closeNaturally(
                        definition.goal
                    )
                );
            }
            break;


        case AI_CLOSED:
            if (stage == COMPLETED) {
                transitionTo(
                    CLOSING,
                    "closed"
                );
            } else {
                // AI 提前告别不能破坏状态机
                status =
                    "premature_closing_detected";
            }
            break;


        case UNEXPECTED_REQUEST:
            status = "needs_recovery";
            break;


        case TRANSCRIPT_CORRECTED:
            // 字幕已在 correctTurn 中替换
            // 不改变业务状态
            break;
    }
}


private boolean hasAllRequiredSlots() {
    for (String requiredKey
            : definition.requiredSlotKeys()) {

        if (!order.containsKey(requiredKey)
                || isBlank(order.get(requiredKey))) {
            return false;
        }
    }

    return true;
}
```

### 7.7 发现任务完成后自然结束并自动关麦

```javascript
async function pollState() {
    session = await GET(
        `/api/demo/sessions/${session.id}`
    );


    // =====================================================
    // 1. 将新的状态机控制指令发送给 Realtime 模型
    // =====================================================

    List<ControlInstruction> newControls =
        session.controlInstructions.after(
            sentControlCount
        );

    for (ControlInstruction control
            : newControls) {

        sendProvider({
            type: "session.update",
            session: {
                instructions:
                    session.definition.realtimeInstruction
                    + "\n\n"
                    + control.instruction
            }
        });
    }

    sentControlCount =
        session.controlInstructions.length;


    // =====================================================
    // 2. COMPLETED 后立即停止收音
    // =====================================================

    if (session.stage == COMPLETED
            && !naturalCloseArmed) {
        armNaturalClose();
    }
}


function armNaturalClose() {
    naturalCloseArmed = true;

    // 用户此时继续说话也不会再上传给模型
    microphoneTrack.enabled = false;
    muteButton.disabled = true;

    showStatus(
        "任务已确认，麦克风已关闭，等待 AI 最后一句"
    );

    if (!assistantResponseActive
            && lastResponseDoneAt > lastUserTranscriptAt) {

        // 最终回复已经完成
        scheduleFinalDisconnect(900);
    } else {

        // 异常情况下最多等待 5 秒
        scheduleFinalDisconnect(5000);
    }
}


async function finalizeNaturalClose() {
    // =====================================================
    // 3. 后端状态进入 CLOSING
    // =====================================================

    session = await POST(
        `/api/demo/sessions/${session.id}/close`
    );

    // 后端只会在 COMPLETED 状态应用 AI_CLOSED


    // =====================================================
    // 4. 关闭所有媒体和传输资源
    // =====================================================

    dataChannel.close();
    peerConnection.close();

    for (MediaStreamTrack track
            : localStream.getTracks()) {
        track.stop();
    }

    clearInterval(pollTimer);

    showStatus(
        "场景已自然结束，麦克风和连接均已关闭"
    );
}
```

## 八、关键保护规则

```text
1. 自定义话题不对应固定状态字段
   requiredSlots 每次由场景生成模型动态生成。

2. 大模型不能绕过必填槽位
   USER_CONFIRMED 只有在 hasAllRequiredSlots() 为 true 时才能完成。

3. AI 不得默认尺寸或数量
   点单/购买场景缺少 size/quantity 时，由生成器确定性补槽位。

4. 修正不是新订单
   CORRECTION 覆盖旧值、增加 revision，并重新进入确认流程。

5. AI 提前告别不是正常结束
   非 COMPLETED 状态的 AI_CLOSED 只记录诊断，不关闭状态机。

6. 完成指令必须幂等
   controlInstructions 为空时才生成 closeNaturally 指令。

7. 完成后用户不能继续触发回复
   进入 COMPLETED 时立即禁用麦克风轨道，而不是只要求 AI 不说话。

8. 最后一句不能被截断
   先关麦，等待 response.done，再关闭 DataChannel 和 WebRTC。

9. 语义抽取不能拖慢实时声音
   AI 音频走 WebRTC 直通；用户语义抽取异步串行执行。

10. 字幕先实时、后纠错
    delta 事件负责流式展示，completed 字幕经语义模型纠错后替换最终文本。
```
