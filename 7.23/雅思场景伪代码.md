# 雅思场景伪代码

> 本文参考《自定义场景伪代码.md》的“小树 + 完整流程伪代码”写法。
>
> 本文使用 Java 风格伪代码描述目标架构，重点表达职责、顺序、状态和调用关系，不要求代码可以直接编译。
>
> 雅思模块没有单词、词组、句子等 Learning 阶段。它的核心流程是：题库校验 → 确定性组卷 → 创建 Attempt → Realtime 考试 → 音频与原始字幕采集 → 考试结束统一评分 → 五维训练报告。

## 一、雅思考试准备与流程小树

```text
雅思考试准备与状态流转

IeltsExamFlowService
├── 作用：编排雅思试卷组装、考试阶段切换、计时和考试结束
├── generateScene(command) -> IeltsPaperSnapshot
│   └── 加载并校验题库，按照考试模式组装不可变试卷快照
├── getCurrentStage(attemptId) -> IeltsStageResult
│   └── 返回当前阶段、当前 Part、当前题目和 PaperSnapshot
├── advanceStage(attemptId, event) -> IeltsStageTransitionResult
│   └── 根据状态机事件推进考试，不允许任意跳转
├── validateRealtimeSessionStart(attemptId) -> IeltsSessionPreparation
│   └── 校验 Attempt 和试卷快照，并取得考官 Prompt
├── startPart2Preparation(attemptId) -> IeltsStageTransitionResult
│   └── 进入 Part 2 准备阶段并启动准备倒计时
├── retryCurrentQuestion(attemptId) -> IeltsStageTransitionResult
│   └── 仅练习模式允许重试当前题目
├── skipCurrentQuestion(attemptId) -> IeltsStageTransitionResult
│   └── 仅练习模式允许跳过并进入下一题
├── completeScene(attemptId) -> FinalizeIeltsAttemptResult
│   └── 进入 REPORT 阶段并触发整场评分
└── abandonAttempt(attemptId) -> void
    └── 将考试标记为 ABANDONED，并停止连接、计时器和评分任务
│
├── IeltsQuestionBankService
│   ├── 作用：加载并校验原子化雅思题库
│   └── loadAndValidate() -> IeltsQuestionBank
│       ├── 加载 manifest、Part 1 题组和 Part 2/Part 3 组合
│       ├── 校验版本、Schema、ID 唯一性、eligible 和题目顺序
│       └── 保证 Part 2 卡片和 Part 3 追问题属于同一 Topic
│
├── IeltsPaperAssemblerService
│   ├── 作用：从已校验题库中确定性组装本次考试试卷
│   ├── generate(command) -> IeltsPaperSnapshot
│   └── assemble(bank, options) -> IeltsPaperSnapshot
│       ├── 支持 full_mock 和 practice_part
│       ├── 支持 real_exam 和 accelerated_demo
│       ├── Part 1 从同一 Topic 选择四至五道不重复题目
│       ├── Part 2 与 Part 3 使用同一原子 Topic 组合
│       ├── 优先避开最近五次完成考试使用过的题目
│       └── 写入题库、Schema、Prompt、计时版本并深度冻结
│
├── IeltsAttemptService
│   ├── 作用：管理一次雅思考试及其生命周期
│   ├── createAttempt(userId, mode, paperSnapshot) -> IeltsAttempt
│   ├── getAttempt(attemptId) -> IeltsAttempt
│   ├── setCurrentStage(attemptId, stage) -> void
│   ├── setPaperSnapshot(attemptId, paperSnapshot) -> void
│   ├── setTranscript(attemptId, turnId, rawTranscript) -> void
│   ├── finalizeAttempt(attemptId) -> FinalizeIeltsAttemptResult
│   ├── getScoringStatus(attemptId) -> IeltsScoringStatus
│   ├── getReport(attemptId) -> IeltsReport
│   ├── abandonAttempt(attemptId) -> void
│   └── deleteAttempt(attemptId) -> void
│
├── IeltsFlowStateService
│   ├── 作用：保存并校验雅思确定性状态机
│   ├── set(attemptId, stage) -> void
│   ├── get(attemptId) -> IeltsStage
│   └── transition(attemptId, event) -> IeltsStageTransitionResult
│       └── 非法事件只返回错误，不改变当前状态
│
└── IeltsExamTimerService
    ├── 作用：管理各阶段答题时间和 Part 2/Part 3 特殊计时
    ├── startAnswerTimer(attemptId, seconds) -> void
    ├── startPreparationTimer(attemptId, seconds) -> void
    ├── startPart3OverallTimer(attemptId, softLimit, hardLimit) -> void
    └── cancelAll(attemptId) -> void
```

├── IeltsSessionWebSocketHandler

├── IeltsScoringStreamHandler

    ├── finishAudio(attemptId, turnId, reason) -> void
    ├── setTranscript(attemptId, turnId, rawTranscript) -> void

## 三、雅思最终评分小树

```text
雅思考试结束评分

IeltsScoringOrchestrator
├── 作用：汇总整场证据，并生成官方四项 + 训练第五维报告
├── score(attempt) -> CompletableFuture<IeltsReport>
│   ├── 等待评分音频流完成
│   ├── 过滤可评分轮次
│   ├── 计算客观流利度指标
│   ├── 并行获取讯飞发音证据
│   ├── 第一阶段提取语言证据
│   ├── 第二阶段完成整体裁判
│   ├── 由本地代码计算 Overall
│   ├── 映射五维雷达图
│   └── 发布 COMPLETE、PARTIAL 或 UNSCORABLE 报告
│
├── IeltsTurnAssembler
│   ├── 作用：把 PCM、VAD 片段、原始字幕和显式结束事件组装为 IeltsTurn
│   ├── open(...) -> IeltsTurn
│   ├── appendPcm(pcmChunk) -> void
│   ├── speechStarted(turnId, timestamp) -> void
│   ├── speechStopped(turnId, timestamp) -> void
│   ├── transcript(turnId, rawTranscript) -> void
│   ├── complete(turnId, timestamp, reason) -> void
│   └── finishStream() -> void
│
├── IeltsAcousticFeatureService
│   ├── 作用：从时间戳、VAD 片段和原始字幕计算客观流利度指标
│   └── calculate(turn) -> IeltsAcousticMetrics
│       └── 包含回答时长、发声时长、静音比例、语速、停顿、填充词和响应延迟
│
├── PronunciationEvidenceProvider
│   ├── 作用：为每个可评分轮次获取外部发音证据
│   └── evaluate(turn) -> CompletableFuture<PronunciationEvidence>
│       │
│       └── XfyunPronunciationEvidenceProvider
│           └── 调用讯飞 ISE；当前 read_sentence 能力只作为低置信证据
│
├── IeltsTwoStageTextScorer
│   ├── 作用：把语言分析与最终整体裁判拆成两个阶段
│   ├── languageEvidence(structuredInput) -> CompletableFuture<Map>
│   └── holisticJudge(combinedInput) -> CompletableFuture<Map>
│       │
│       └── QwenIeltsTextScorer
│           └── 调用千问评分模型并要求严格 JSON
│
├── IeltsBandCalculator
│   ├── 作用：只用四个 IELTS 官方维度计算 Overall
│   └── calculate(fc, lr, gra, pronunciation) -> IeltsBandResult
│       └── 四项平均后按 0.5 Band 取整；任一项缺失则 Overall 为 null
│
└── IeltsRadarMapper
    ├── 作用：生成前端五维雷达图数据
    └── map(fc, lr, gra, pronunciation, taskAchievement)
        -> List<RadarDimension>
        ├── FC、LR、GRA、P：Band 0–9 映射为 0–100
        └── TA：直接使用训练评分 0–100，绝不参与 Overall
```

## 五、完整 Java 风格伪代码

```java
public IeltsReport runIeltsSpeaking(
        StartIeltsExamCommand command) {

    // =====================================================
    // 1. 读取当前用户并校验开始考试所需参数
    // =====================================================

    // 获取当前登录用户；后续 Attempt 必须绑定到该用户。
    String userId =
        AuthService.getCurrentUserId();

    // 只允许完整模考或单 Part 练习两种模式。
    if (!Set.of("full_mock", "practice_part")
            .contains(command.getMode())) {
        throw new IllegalArgumentException(
            "mode must be full_mock or practice_part"
        );
    }

    // 单 Part 练习必须明确选择 part1、part2 或 part3。
    if (command.getMode().equals("practice_part")) {
        validateSelectedPart(
            command.getSelectedPart()
        );
    }

    // 完整模考默认使用正式计时；练习或演示可以使用加速计时。
    String timingProfile =
        resolveTimingProfile(
            command.getMode(),
            command.isAcceleratedDemo()
        );


    // =====================================================
    // 2. 加载并校验雅思题库
    // =====================================================

    // 读取 manifest、Part 1 文件和 Part 2/Part 3 原子组合文件。
    IeltsQuestionBank questionBank =
        IeltsQuestionBankService.loadAndValidate();

    // loadAndValidate 内部必须保证：
    // 1) bankVersion 和 schemaVersion 合法；
    // 2) 所有 groupId、questionId、topicId 全局唯一；
    // 3) 至少有一个可用 Part 1 题组；
    // 4) 至少有一个可用 Part 2/Part 3 原子组合；
    // 5) Part 2 卡片和 Part 3 追问题属于同一 Topic。


    // =====================================================
    // 3. 组装本次考试的不可变 PaperSnapshot
    // =====================================================

    // 读取最近五次已完成考试用过的题目，用于优先避让重复题。
    Set<String> recentQuestionIds =
        IeltsAttemptHistoryService
            .getRecentQuestionIds(
                userId,
                5
            );

    // 记录本次使用的 Prompt 版本，确保报告可以追溯。
    String promptVersion =
        IeltsPromptService.getPromptVersion();

    // 从已校验题库中组装试卷，而不是让大模型临时生成题目。
    IeltsPaperSnapshot paperSnapshot =
        IeltsPaperAssemblerService.assemble(
            questionBank,
            new IeltsPaperAssemblyOptions(
                command.getMode(),
                command.getSelectedPart(),
                timingProfile,
                recentQuestionIds,
                promptVersion
            )
        );

    // PaperSnapshot 一旦创建便不可修改。
    // 后续考官发问、评分和审计都使用这里冻结的题目文本。


    // =====================================================
    // 4. 创建 IeltsAttempt 并初始化状态机
    // =====================================================

    // Attempt 是一次考试的聚合根，保存试卷、轮次、状态和最终报告。
    IeltsAttempt attempt =
        IeltsAttemptService.createAttempt(
            userId,
            command.getMode(),
            paperSnapshot
        );

    String attemptId =
        attempt.getAttemptId();

    // 新建考试首先处于 READY，尚未向考生播放开场语。
    IeltsFlowStateService.set(
        attemptId,
        IeltsStage.READY
    );


    // =====================================================
    // 5. 校验 Realtime 会话并构建考官 Prompt
    // =====================================================

    // 再次确认 Attempt 有效、属于当前用户且包含完整 PaperSnapshot。
    IeltsExamFlowService
        .validateRealtimeSessionStart(
            attemptId
        );

    // 构建考官系统 Prompt。
    // Prompt 只规定考官行为，不允许模型自行选题或推进 Part。
    IeltsExaminerPrompt examinerPrompt =
        IeltsPromptService.getExaminerPrompt(
            new IeltsPromptContext(
                attemptId,
                paperSnapshot,
                promptVersion
            )
        );

    // Prompt 必须明确：
    // 1) 考官只说英语；
    // 2) 考试中不教学、不纠错、不评分；
    // 3) 只能朗读固定指令或 PaperSnapshot 中的冻结题目；
    // 4) 状态切换和计时完全由确定性状态机控制。


    // =====================================================
    // 6. 建立 Realtime 会话和雅思评分 WebSocket
    // =====================================================

    // 创建本地会话对象，并绑定 Attempt。
    IeltsSession session =
        IeltsSessionService.createSession(
            attemptId
        );

    // 使用 offer SDP 与 Realtime Provider 完成 WebRTC/SDP 交换。
    IeltsSessionStartResult startResult =
        IeltsSessionService.start(
            attemptId,
            examinerPrompt,
            command.getOfferSdp()
        );

    String localSessionId =
        startResult.getLocalSessionId();

    // 打开独立评分 WebSocket。
    // 二进制消息传 PCM；文本消息传 part.started、turn.opened 等控制事件。
    IeltsScoringStream scoringStream =
        IeltsScoringStreamService.open(
            attemptId,
            localSessionId
        );

    // 评分 WebSocket 使用 16 kHz、16-bit、mono PCM。
    scoringStream.sendControl(
        IeltsScoringEvent.streamStart(
            attemptId
        )
    );


    // =====================================================
    // 7. 完整模考开场与 Introduction
    // =====================================================

    if (command.getMode().equals("full_mock")) {

        // START 事件只能让 READY 进入 OPENING。
        IeltsExamFlowService.advanceStage(
            attemptId,
            IeltsExamEvent.START
        );

        // 朗读固定开场语；模型不能在这里自行出题。
        IeltsSessionService.sayExactInstruction(
            localSessionId,
            examinerPrompt.getOpening()
        );

        // 考官开场语播放完成后进入 INTRODUCTION。
        IeltsExamFlowService.advanceStage(
            attemptId,
            IeltsExamEvent.EXAMINER_DONE
        );

        // Introduction 只用于设备、会话和自我介绍体验，不参与评分。
        String introductionTurnId =
            IeltsEvaluationService.start(
                attemptId,
                0,
                FrozenQuestion.introduction(),
                false
            );

        // 开始 Introduction 回答计时。
        IeltsExamTimerService.startAnswerTimer(
            attemptId,
            paperSnapshot.getTiming()
                .getIntroductionMaxSeconds()
        );

        // 流式接收 Introduction PCM。
        while (candidateAudio.hasNextChunk()) {
            byte[] pcmChunk =
                candidateAudio.nextChunk();

            IeltsEvaluationService.setAudio(
                attemptId,
                introductionTurnId,
                pcmChunk
            );
        }

        // 保存原始字幕，但 scoringEligible=false，最终评分会排除此轮。
        IeltsEvaluationService.setTranscript(
            attemptId,
            introductionTurnId,
            candidateTranscript.getRawText()
        );

        // 必须由用户完成或时间上限显式结束逻辑轮次。
        IeltsEvaluationService.finishAudio(
            attemptId,
            introductionTurnId,
            CompletionReason.USER_DONE
        );

        // 提交 Introduction 后，状态机进入 Part 1。
        IeltsExamFlowService.advanceStage(
            attemptId,
            IeltsExamEvent.SUBMIT_ANSWER
        );
    }


    // =====================================================
    // 8. Part 1：同一 Topic 的四至五道短答题
    // =====================================================

    if (paperSnapshot.hasPart1()) {

        // 完整模考先播放 Part 1 固定过渡语。
        if (command.getMode().equals("full_mock")) {
            IeltsSessionService.sayExactInstruction(
                localSessionId,
                examinerPrompt.getPart1Start()
            );
        }

        for (IeltsQuestion question
                : paperSnapshot.getPart1().getQuestions()) {

            // 考官只能朗读 PaperSnapshot 中被冻结的题目文本。
            IeltsSessionService.askFrozenQuestion(
                localSessionId,
                question.getRenderedText()
            );

            // 为本题创建一个可评分轮次。
            String turnId =
                IeltsEvaluationService.start(
                    attemptId,
                    1,
                    question,
                    true
                );

            // 告知评分流当前 Part 和题目快照。
            scoringStream.sendControl(
                IeltsScoringEvent.questionAsked(
                    turnId,
                    1,
                    question.getQuestionId(),
                    question.getRenderedText()
                )
            );

            // 启动本题回答倒计时。
            IeltsExamTimerService.startAnswerTimer(
                attemptId,
                paperSnapshot.getTiming()
                    .getPart1AnswerMaxSeconds()
            );

            // WebSocket 每收到一个 PCM 分片便追加到当前轮次。
            while (candidateAudio.hasNextChunk()) {
                IeltsEvaluationService.setAudio(
                    attemptId,
                    turnId,
                    candidateAudio.nextChunk()
                );
            }

            // 只保存 ASR 原始结果，不保存模型润色后的表达。
            IeltsEvaluationService.setTranscript(
                attemptId,
                turnId,
                candidateTranscript.getRawText()
            );

            // 由用户点击完成或倒计时到期结束本题。
            IeltsEvaluationService.finishAudio(
                attemptId,
                turnId,
                candidateAnswerCompletionReason
            );

            // 考试过程中只向前端确认 TURN_CAPTURED，不返回即时分数。
            TurnCapturedResult captured =
                IeltsEvaluationService.getTurnResult(
                    attemptId,
                    turnId
                );

            // 练习模式可以重试或跳过；这些废弃轮次不会进入最终评分。
            if (command.getMode().equals("practice_part")
                    && userAction == UserAction.RETRY) {
                IeltsEvaluationService.finishAudio(
                    attemptId,
                    turnId,
                    CompletionReason.PRACTICE_RETRY
                );
                IeltsExamFlowService.retryCurrentQuestion(
                    attemptId
                );
                continue;
            }

            if (command.getMode().equals("practice_part")
                    && userAction == UserAction.NEXT) {
                IeltsEvaluationService.finishAudio(
                    attemptId,
                    turnId,
                    CompletionReason.PRACTICE_SKIP
                );
                IeltsExamFlowService.skipCurrentQuestion(
                    attemptId
                );
                continue;
            }

            // 正常提交后进入 Part 1 下一题；最后一题后进入 Part 2 或完成练习。
            IeltsExamFlowService.advanceStage(
                attemptId,
                IeltsExamEvent.SUBMIT_ANSWER
            );
        }
    }


    // =====================================================
    // 9. Part 2：一分钟准备 + 长回答
    // =====================================================

    if (paperSnapshot.hasPart2()) {

        IeltsPart2Card part2Card =
            paperSnapshot.getPart2();

        // 进入准备阶段，只有此阶段允许编辑笔记。
        IeltsExamFlowService.startPart2Preparation(
            attemptId
        );

        // 朗读固定准备说明并展示冻结的题卡和 cue points。
        IeltsSessionService.sayExactInstruction(
            localSessionId,
            examinerPrompt.getPart2Preparation()
        );

        // 使用试卷快照中的准备时长启动倒计时。
        IeltsExamTimerService.startPreparationTimer(
            attemptId,
            part2Card.getPrepSeconds()
        );

        // 准备阶段允许考生记录笔记，但笔记不作为评分证据。
        while (!IeltsExamTimerService.isExpired(attemptId)) {
            IeltsAttemptService.setPart2Notes(
                attemptId,
                candidateNotes.getCurrentText()
            );
        }

        // PREP_EXPIRED 只能从 PART2_PREPARING 进入 PART2_ANSWERING。
        IeltsExamFlowService.advanceStage(
            attemptId,
            IeltsExamEvent.PREP_EXPIRED
        );

        // 准备结束后锁定笔记并播放开始作答指令。
        IeltsAttemptService.lockPart2Notes(
            attemptId
        );

        IeltsSessionService.sayExactInstruction(
            localSessionId,
            examinerPrompt.getPart2Start()
        );

        // Part 2 使用长回答轮次，明确标记 PART2_LONG_TURN。
        String part2TurnId =
            IeltsEvaluationService.startLongTurn(
                attemptId,
                2,
                part2Card,
                true
            );

        // 启动 Part 2 最大回答时长计时。
        IeltsExamTimerService.startAnswerTimer(
            attemptId,
            part2Card.getAnswerMaxSeconds()
        );

        while (!candidateFinished
                && !IeltsExamTimerService.isExpired(attemptId)) {

            // 持续追加 PCM 音频。
            IeltsEvaluationService.setAudio(
                attemptId,
                part2TurnId,
                candidateAudio.nextChunk()
            );

            // VAD speech_stopped 只结束一个发声片段。
            // Part 2 的短暂停顿绝不能自动结束整个长回答。
            if (realtimeEvent.isSpeechStopped()) {
                IeltsEvaluationService.markSpeechStopped(
                    attemptId,
                    part2TurnId,
                    realtimeEvent.getTimestamp()
                );
            }
        }

        // 保存 Part 2 完整原始字幕。
        IeltsEvaluationService.setTranscript(
            attemptId,
            part2TurnId,
            candidateTranscript.getRawText()
        );

        // 只有显式完成或时间上限才能结束 Part 2 逻辑轮次。
        IeltsEvaluationService.finishAudio(
            attemptId,
            part2TurnId,
            candidateFinished
                ? CompletionReason.USER_DONE
                : CompletionReason.TIME_LIMIT
        );

        // 完整模考进入 Part 3；单 Part 练习直接完成。
        IeltsExamFlowService.advanceStage(
            attemptId,
            IeltsExamEvent.SUBMIT_ANSWER
        );
    }


    // =====================================================
    // 10. Part 3：追问题与整体软/硬时间上限
    // =====================================================

    if (paperSnapshot.hasPart3()) {

        // 完整模考先播放 Part 3 固定过渡语。
        if (command.getMode().equals("full_mock")) {
            IeltsSessionService.sayExactInstruction(
                localSessionId,
                examinerPrompt.getPart3Start()
            );
        }

        // Part 3 除单题计时外，还有整个 Part 的软、硬时间上限。
        IeltsExamTimerService.startPart3OverallTimer(
            attemptId,
            paperSnapshot.getTiming()
                .getPart3SoftLimitSeconds(),
            paperSnapshot.getTiming()
                .getPart3HardLimitSeconds()
        );

        for (IeltsQuestion question
                : paperSnapshot.getPart3().getQuestions()) {

            // 达到软时间上限后，当前回答结束即可完成 Part 3。
            if (IeltsExamTimerService
                    .isPart3SoftLimitReached(attemptId)) {
                IeltsExamFlowService.advanceStage(
                    attemptId,
                    IeltsExamEvent.PART3_SOFT_LIMIT
                );
            }

            // 达到硬时间上限时立即结束 Part 3。
            if (IeltsExamTimerService
                    .isPart3HardLimitReached(attemptId)) {
                IeltsExamFlowService.advanceStage(
                    attemptId,
                    IeltsExamEvent.PART3_HARD_LIMIT
                );
                break;
            }

            // 朗读与 Part 2 同 Topic 的冻结追问题。
            IeltsSessionService.askFrozenQuestion(
                localSessionId,
                question.getRenderedText()
            );

            // 创建 Part 3 可评分轮次。
            String turnId =
                IeltsEvaluationService.start(
                    attemptId,
                    3,
                    question,
                    true
                );

            // 启动本题回答计时。
            IeltsExamTimerService.startAnswerTimer(
                attemptId,
                paperSnapshot.getTiming()
                    .getPart3AnswerMaxSeconds()
            );

            // 流式接收本题 PCM。
            while (candidateAudio.hasNextChunk()) {
                IeltsEvaluationService.setAudio(
                    attemptId,
                    turnId,
                    candidateAudio.nextChunk()
                );
            }

            // 保存本题原始字幕。
            IeltsEvaluationService.setTranscript(
                attemptId,
                turnId,
                candidateTranscript.getRawText()
            );

            // 显式结束本题。
            IeltsEvaluationService.finishAudio(
                attemptId,
                turnId,
                candidateAnswerCompletionReason
            );

            // 推进下一道 Part 3 题或进入 COMPLETED。
            IeltsExamFlowService.advanceStage(
                attemptId,
                IeltsExamEvent.SUBMIT_ANSWER
            );
        }
    }


    // =====================================================
    // 11. 正常结束考试并封闭评分音频流
    // =====================================================

    // 播放固定结束语；此时不再允许创建新评分轮次。
    IeltsSessionService.sayExactInstruction(
        localSessionId,
        examinerPrompt.getEnding()
    );

    // 等待 700ms post-roll，避免吞掉回答尾部音频。
    waitMillis(750);

    // 显式发送 stream.end，让后端完成所有缓冲轮次。
    scoringStream.sendControl(
        IeltsScoringEvent.streamEnd(
            attemptId
        )
    );

    // 标记评分流已完成；最终评分必须在此信号之后开始。
    IeltsScoringStreamService.finishStream(
        attemptId
    );

    // 进入 FINALIZING，并异步触发整场评分。
    IeltsAttemptService.finalizeAttempt(
        attemptId
    );


    // =====================================================
    // 12. 过滤真正可评分的考试轮次
    // =====================================================

    List<IeltsTurn> scoringTurns =
        IeltsAttemptService.getTurns(attemptId)
            .stream()
            // Introduction 不属于 IELTS 评分内容。
            .filter(turn -> turn.getPart() >= 1)
            .filter(turn -> turn.getPart() <= 3)
            // 只保留创建时明确标记为可评分的轮次。
            .filter(IeltsTurn::isScoringEligible)
            // 未显式完成的轮次不能进入评分。
            .filter(IeltsTurn::isCompleted)
            // 练习模式中被重试或跳过的废弃轮次不能进入评分。
            .filter(turn -> !Set.of(
                "PRACTICE_RETRY",
                "PRACTICE_SKIP"
            ).contains(turn.getCompletionReason()))
            .toList();

    // 没有可评分回答时直接生成 UNSCORABLE 报告，不调用模型伪造分数。
    if (scoringTurns.isEmpty()) {
        return IeltsReport.unscorable(
            attemptId,
            "没有可评分回答"
        );
    }


    // =====================================================
    // 13. 计算本地客观流利度指标
    // =====================================================

    List<IeltsTurnEvidence> turnEvidence =
        new ArrayList<>();

    for (IeltsTurn turn : scoringTurns) {

        // 根据回答时间、发声片段和原始字幕计算客观指标。
        IeltsAcousticMetrics metrics =
            IeltsAcousticFeatureService.calculate(
                turn
            );

        // 指标包括回答时长、发声时长、静音比例、语速、
        // 停顿次数、长停顿、填充词、首词延迟等。
        turnEvidence.add(
            IeltsTurnEvidence.from(
                turn,
                metrics
            )
        );
    }


    // =====================================================
    // 14. 并行获取讯飞发音证据
    // =====================================================

    List<CompletableFuture<PronunciationEvidence>>
        pronunciationFutures =
            scoringTurns.stream()
                .map(turn ->
                    PronunciationEvidenceProvider
                        .evaluate(turn)
                        // 单轮外部发音服务最多等待 60 秒。
                        .orTimeout(60, TimeUnit.SECONDS)
                        // 单轮失败只产生警告，不让整场报告直接崩溃。
                        .exceptionally(error ->
                            PronunciationEvidence.failure(
                                error.getMessage()
                            )
                        )
                )
                .toList();

    // 等待所有发音证据任务完成。
    CompletableFuture.allOf(
        pronunciationFutures.toArray(
            CompletableFuture[]::new
        )
    ).join();

    List<PronunciationEvidence> pronunciationEvidence =
        pronunciationFutures.stream()
            .map(CompletableFuture::join)
            .toList();

    // 当前讯飞 read_sentence 模式不是自由口语官方评分。
    // 它只能作为低置信辅助证据，不能直接当作 IELTS Band。


    // =====================================================
    // 15. 第一阶段：提取 FC、LR、GRA 语言证据
    // =====================================================

    Map<String, Object> structuredInput =
        IeltsScoringInputBuilder.build(
            attempt,
            turnEvidence,
            pronunciationEvidence
        );

    // structuredInput 只放 Part 1/2/3 的 rawTranscript、
    // 冻结题目、回答时长、客观指标和数据质量警告。
    // 绝不放 Introduction 或纠正后的推荐表达。

    ScoringPrompt languagePrompt =
        IeltsPromptService
            .buildLanguageEvidencePrompt(
                structuredInput
            );

    Map<String, Object> languageEvidence =
        IeltsTwoStageTextScorer
            .languageEvidence(
                structuredInput,
                languagePrompt
            )
            .join();

    // 第一阶段只提取流利度与连贯性、词汇资源、
    // 语法多样性与准确性，不允许返回 Overall。


    // =====================================================
    // 16. 第二阶段：整场裁判与训练第五维
    // =====================================================

    Map<String, Object> judgeInput =
        new LinkedHashMap<>(
            structuredInput
        );

    // 把第一阶段语言证据加入整场裁判输入。
    judgeInput.put(
        "language_evidence",
        languageEvidence
    );

    ScoringPrompt judgePrompt =
        IeltsPromptService.buildJudgePrompt(
            judgeInput
        );

    Map<String, Object> judgeResult =
        IeltsTwoStageTextScorer
            .holisticJudge(
                judgeInput,
                judgePrompt
            )
            .join();

    // 第二阶段返回：FC、LR、GRA、P、TA、证据、置信度、
    // Band 区间和 Part 总结，但仍然不允许模型返回 Overall。


    // =====================================================
    // 17. 本地代码计算 IELTS 官方 Overall
    // =====================================================

    IeltsDimensionResult fc =
        IeltsDimensionResult.from(
            judgeResult.get("fluency_coherence")
        );

    IeltsDimensionResult lr =
        IeltsDimensionResult.from(
            judgeResult.get("lexical_resource")
        );

    IeltsDimensionResult gra =
        IeltsDimensionResult.from(
            judgeResult.get(
                "grammatical_range_accuracy"
            )
        );

    IeltsDimensionResult pronunciation =
        IeltsDimensionResult.from(
            judgeResult.get("pronunciation")
        );

    TaskAchievementResult taskAchievement =
        TaskAchievementResult.from(
            judgeResult.get("task_achievement")
        );

    // Overall 只能由四个 IELTS 官方维度计算。
    IeltsBandResult bandResult =
        IeltsBandCalculator.calculate(
            fc.getBand(),
            lr.getBand(),
            gra.getBand(),
            pronunciation.getBand()
        );

    // 四项齐全：平均后按 0.5 Band 取整。
    // 任一官方维度缺失：Overall 保持 null，状态为 PARTIAL。
    // TA 永远不能传入 IeltsBandCalculator。


    // =====================================================
    // 18. 生成前端五维雷达图数据
    // =====================================================

    List<RadarDimension> radarDimensions =
        IeltsRadarMapper.map(
            fc,
            lr,
            gra,
            pronunciation,
            taskAchievement
        );

    // FC、LR、GRA、P 从 0–9 Band 映射为 0–100。
    // TA 本身就是 0–100 的训练诊断分数。
    // 缺失维度保持 null，前端显示“不可用”，不能显示为 0。


    // =====================================================
    // 19. 组装并保存最终报告
    // =====================================================

    IeltsScoringStatus finalStatus =
        bandResult.getOverallBand() == null
            ? IeltsScoringStatus.PARTIAL
            : IeltsScoringStatus.COMPLETE;

    IeltsReport report =
        new IeltsReport(
            attemptId,
            finalStatus,
            bandResult.getOverallBand(),
            judgeResult.getBandRange(),
            judgeResult.getConfidence(),
            fc,
            lr,
            gra,
            pronunciation,
            taskAchievement,
            radarDimensions,
            judgeResult.getPartSummaries(),
            collectDataQualityWarnings(),
            IeltsScoringOrchestrator.DISCLAIMER
        );

    // 先更新本地报告，保证查询接口立即看到最终状态。
    IeltsAttemptService.setReport(
        attemptId,
        report
    );

    // 再异步持久化报告；失败应记录日志并允许重试。
    IeltsAttemptService.saveReportAsync(
        attemptId,
        report
    );


    // =====================================================
    // 20. 进入 REPORT、保存历史并清理连接
    // =====================================================

    // 状态机进入 REPORT，前端可以读取最终报告。
    IeltsFlowStateService.set(
        attemptId,
        IeltsStage.REPORT
    );

    // 只有正常完成的考试才写入最近题目历史。
    IeltsAttemptHistoryService
        .saveCompletedAttempt(
            userId,
            attemptId,
            paperSnapshot
        );

    // 正常关闭 Realtime 和评分 WebSocket。
    IeltsSessionService.close(
        localSessionId
    );

    IeltsScoringStreamService.close(
        attemptId
    );

    // 取消全部计时器，防止旧考试回调污染新考试。
    IeltsExamTimerService.cancelAll(
        attemptId
    );

    // 结算本次 Realtime 与评分资源用量。
    UsageQuotaService.settle(
        userId,
        localSessionId
    );

    return report;
}
```

## 六、异常退出伪代码

```java
public void abandonIeltsAttempt(
        String attemptId,
        String localSessionId) {

    // 用户主动退出或启动失败时，将 Attempt 标记为 ABANDONED。
    IeltsAttemptService.abandonAttempt(
        attemptId
    );

    // 状态机进入终态后，不再接受新的状态转换。
    IeltsFlowStateService.set(
        attemptId,
        IeltsStage.ABANDONED
    );

    // 取消尚未完成的评分 Future，防止退出后又发布旧报告。
    IeltsScoringTaskService.cancelAll(
        attemptId
    );

    // 使评分 WebSocket 失效并关闭 PCM 流。
    IeltsScoringStreamService.invalidate(
        attemptId
    );

    // 关闭 Realtime 会话和媒体轨道。
    IeltsSessionService.close(
        localSessionId
    );

    // 取消 Part 2、Part 3 和单题计时器。
    IeltsExamTimerService.cancelAll(
        attemptId
    );

    // 未正式使用或未完成的额度需要释放，而不是结算为完整考试。
    UsageQuotaService.release(
        localSessionId
    );
}
```

## 七、必须遵守的实现规则

```text
1. 题目必须来自已校验并冻结的 PaperSnapshot，考官模型不能自行选题、改题或加题。
2. Introduction 永远不参与 IELTS Band 评分。
3. 评分只使用 rawTranscript，不能使用纠正表达或推荐表达。
4. Part 2 的 VAD speech_stopped 只表示短暂停顿，不能结束长回答。
5. 完整模考过程中不返回单题分数，只返回 TURN_CAPTURED。
6. 练习重试和跳过产生的废弃轮次必须从最终评分中排除。
7. 最终评分必须等待 stream.end 和音频 post-roll 完成。
8. 千问只给四项 Band 建议和 TA，不得直接决定 Overall。
9. Overall 只由 FC、LR、GRA、P 四项平均并按 0.5 Band 取整。
10. TA 是 UniSpeaking 训练第五维，取值 0–100，不属于 IELTS 官方评分项。
11. 缺失分数必须保留 null，不能用 0 补齐。
12. 外部发音服务失败时允许生成 PARTIAL 报告，不应伪造发音分数。
13. 报告必须包含 AI 学习用途免责声明。
14. 用户退出后必须取消计时器、评分任务和媒体连接，旧异步结果不得覆盖新考试。
```
