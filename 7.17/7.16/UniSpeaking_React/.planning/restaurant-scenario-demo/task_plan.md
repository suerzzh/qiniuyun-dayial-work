## 已做决策
| 决策 | 理由 |
|------|------|
| 只对第二张“餐厅特殊需求”卡片启用新逻辑 | 满足路演需求并隔离其他场景 |
| 复用现有实时会话组件和状态机 | 快速交付且避免重复麦克风/WebRTC 资源 |
| 通过场景 ID 让服务端选择提示词 | 提示词和密钥都留在服务端 |

## 遇到的错误
| 错误 | 尝试次数 | 解决方案 |
|------|---------|---------|
| 规划更新补丁因匹配块顺序错误而失败 | 1 | 按文件真实顺序重新排列 patch chunks |
| 前端大补丁因 CSS 媒体查询锚点不匹配而失败 | 1 | 拆分逻辑与样式补丁，使用稳定选择器锚点 |
| 网关补丁因 MODEL 默认值锚点推断错误而失败 | 1 | 读取精确短上下文后按函数分块修改 |
| 浏览器 Permissions API 在自动化上下文不可用 | 1 | 使用页面 session 状态确认麦克风请求已触发 |
| 从前端目录检查 Edge Function 时 Deno 误读上层 Node 类型配置 | 1 | 切换到函数目录运行 `deno check index.ts` |
