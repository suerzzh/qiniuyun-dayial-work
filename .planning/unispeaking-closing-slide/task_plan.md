# UniSpeaking 收束页任务计划

## 目标

生成一张 16:9、3840×2160 的 UniSpeaking 收束页图片，并交付图片型 PPT 与四层可编辑 PPT。

## 阶段

- [x] 明确单页叙事：初步证据 → 下一阶段 → 产品结论
- [x] 锁定品牌色、网格、字体气质和禁止项
- [x] GPT Image 2 生成最终单页图片并做视觉检查
- [x] 合成图片型 PPT 并渲染验证
- [x] imagegen 提取背景、框架、图标三类图片层
- [x] GPT 视觉建立可编辑文字层与位置数据
- [x] 合成可编辑 PPT，完成两轮视觉 QA
- [x] 交付图片、图片型 PPT、可编辑 PPT 和必要中间产物

## 关键决定

- 页面数量：1 页。
- 叙事结构：证据 → 可靠性边界 → 下一阶段 → 产品结论。
- 可见内容仅使用用户提供的标题、数字、要点和结论；完整口播不搬上页面。
- 画面不使用 Logo，避免生成错误品牌字标。
- 图片层全部来自 GPT Image 2；代码仅用于文件组织、抠图、合成和 QA。

## 错误记录

| 错误 | 尝试 | 处理 |
|---|---:|---|
| 更新任务状态时匹配到重复阶段行 | 1 | 读取当前计划，去重后重新更新 |
| 空图标联系表不存在 | 1 | 确认图标表 100% 透明且 manifest 为 0 项，改用统计与 manifest 验证 |
| `shasum` 输出 macOS locale 警告 | 1 | 命令仍以 0 退出并输出三个 SHA-256；不影响文件有效性 |
