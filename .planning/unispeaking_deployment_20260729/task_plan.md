## Decisions Made

| Decision | Rationale |
|---|---|
| 以仓库证据为主，不预设云平台 | 用户要求结合既往经历，必须先还原事实 |
| 只写方案，不直接改 UniSpeaking 业务代码 | 用户当前明确要求把方案写入 7.29 |
| 对未知规模按 MVP/小规模正式上线给出默认假设 | 可直接产出，同时把扩容触发信号单列 |
| 未来完整项目采用 Vercel 前端 + Supabase Auth/Postgres/Storage/Edge Functions | 用户明确指定平台，且历史同类上线已验证 |
| Edge Function 仅做短请求控制面，浏览器与百炼走 WebRTC 媒体面 | 符合无状态平台运行模型并避免服务端持续中转音频 |
| 生产业务函数启用 JWT；匿名 Demo 方案仅作为备选 | 完整产品需要真实身份、对象归属与配额控制 |
