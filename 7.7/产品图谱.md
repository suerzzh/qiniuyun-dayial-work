## 3. 用户旅程图

```mermaid
flowchart LR
    A["触达<br/>小红书/抖音看到<br/>中式英语纠错<br/>外企面试表达<br/>7 天游开口挑战"] --> B["兴趣<br/>觉得场景和自己相关<br/>担心口语但想低压力尝试"]

    B --> C["首次进入<br/>选择目标<br/>外企面试/雅思口语/职场会议/留学生活"]

    C --> D["开始练习<br/>系统给出任务<br/>目标表达<br/>回答时间<br/>鼓励用户先说出来"]

    D --> E["语音表达<br/>用户录音 30-90 秒<br/>AI 转写<br/>用户可查看识别结果"]

    E --> F["AI 追问<br/>根据回答生成一个自然追问<br/>模拟真实对话压力"]

    F --> G["反馈卡<br/>表达亮点<br/>关键问题<br/>原句修改<br/>自然表达<br/>复练任务"]

    G --> H["二次复练<br/>用户根据反馈再说一次<br/>系统对比前后表达"]

    H --> I["进步记录<br/>开口时长<br/>掌握表达<br/>常见问题<br/>连续打卡"]

    I --> J{"是否愿意继续？"}
    J -->|愿意| K["进入连续训练<br/>每日场景<br/>训练营打卡<br/>专项包付费"]
    J -->|犹豫| L["降低门槛<br/>免费再练一次<br/>展示前后对比<br/>推荐低价体验包"]
    J -->|流失| M["召回<br/>面试前提醒<br/>新场景内容<br/>学习报告推送"]

    K --> N["长期价值<br/>表达库沉淀<br/>场景能力提升<br/>付费续费/转介绍"]
```

**关键时刻：** 第一次反馈卡必须足够具体。用户是否觉得“它真的听懂我、能帮我改”，基本决定后续留存和付费。

## 5. 核心用户流程图

```mermaid
flowchart TD
    A["用户打开产品"] --> B["选择练习目标"]
    B --> B1["外企面试"]
    B --> B2["职场会议"]
    B --> B3["雅思口语"]
    B --> B4["留学生活"]

    B1 --> C["系统推荐今日任务"]
    B2 --> C
    B3 --> C
    B4 --> C

    C --> D["展示练习目标<br/>时长<br/>目标表达<br/>回答建议"]
    D --> E["用户录音回答"]
    E --> F["语音转写"]
    F --> G{"转写是否明显错误？"}

    G -->|是| H["用户手动修正或重新录音"]
    H --> E

    G -->|否| I["AI 生成追问"]
    I --> J["用户第二轮回答"]
    J --> K["AI 生成反馈卡"]

    K --> K1["表达亮点"]
    K --> K2["关键问题"]
    K --> K3["原句修改"]
    K --> K4["可复用表达"]
    K --> K5["复练任务"]

    K5 --> L["用户二次复练"]
    L --> M["系统对比前后回答"]
    M --> N["保存学习记录"]
    N --> O{"是否完成今日目标？"}

    O -->|完成| P["展示打卡成功<br/>推荐明日任务"]
    O -->|未完成| Q["降低难度<br/>提供示例答案<br/>鼓励再练一次"]
    Q --> L

    P --> R{"是否进入付费转化？"}
    R -->|高意向| S["推荐专项训练包/7 天训练营"]
    R -->|低意向| T["保留免费练习<br/>推送下一次场景"]
```

**流程重点：** 用户不是进入空白聊天框，而是从明确任务开始；每次练习必须以“复练”和“进步记录”结束。
