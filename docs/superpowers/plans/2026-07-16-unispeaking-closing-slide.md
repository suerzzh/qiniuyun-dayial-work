# UniSpeaking Closing Slide Implementation Plan

> **For agentic workers:** Execute inline in the current session; no subagent dispatch is authorized for this task.

**Goal:** Produce one GPT Image 2 slide image plus an image-only PPTX and a four-layer editable PPTX.

**Architecture:** Stage A creates the final raster slide from a self-contained prompt and wraps it as a full-slide image deck. Stage B uses the selected slide as the only edit target, generates background/frame/icon layers with imagegen, builds editable text boxes from visual inspection, composes the editable deck, then compares the rendered result to the source.

**Tech Stack:** GPT Image 2 built-in image generation, GordenImagePPTGen scripts, GordenImage2PPTX scripts, Pillow, python-pptx as required by the Gorden pipeline, LibreOffice/Poppler-based rendering helpers.

## Global Constraints

- Canvas is 16:9 and final raster target is 3840×2160.
- Use only the exact user-provided claims and numbers.
- Preserve the locked palette and restrained warm editorial visual language.
- Do not generate the slide programmatically or patch text into the bitmap.
- Stage B image layers must each be generated by imagegen.

### Task 1: Generate the source slide

- [ ] Save `outline.json` and the self-contained prompt.
- [ ] Call built-in GPT Image 2 once; inspect the result at full size.
- [ ] If required text or composition is materially wrong, make one targeted edit and re-inspect.
- [ ] Copy the accepted result to `slides/01-unispeaking-closing.png` and record `imagegen-manifest.json`.

### Task 2: Create the image deck

- [ ] Write `deck.json` with the accepted image as the only slide background.
- [ ] Run GordenImagePPTGen `compose_pptx.py`.
- [ ] Render the PPTX and compare it to the accepted image.

### Task 3: Generate editable image layers

- [ ] Create a unique Stage B page directory and copy the accepted source to `slide-01.png`.
- [ ] Probe palette and select the chroma-key color.
- [ ] View the source before every imagegen extraction.
- [ ] Generate background, frame and icon/decoration assets; record all sources and prompt paths.
- [ ] Chroma-key the frame and icons; inspect transparency and integrity.

### Task 4: Build and verify editable text layout

- [ ] Use visual inspection to record source-pixel text boxes, font sizes, colors and weights.
- [ ] Write `layout.json`, `placements.json` and the layer manifest.
- [ ] Run strict layout guard and source-box QA.
- [ ] Compose the editable PPTX and render it.
- [ ] Run placement and visual comparison QA, revise layout at least once, then rerun all checks.

### Task 5: Deliver

- [ ] Copy the final image, image deck and editable deck to stable output paths.
- [ ] Verify file existence, dimensions, slide counts, editable text boxes and render outputs.
