# 雅思模拟模块整体框架

> 基于《自由聊天伪代码.md》的整体框架改造。
>
> 本版只保留“模块框架、继承关系、调用关系和职责说明”，已删除原文件后半部分的自由聊天 Java 伪代码实现。

## 标记说明

- **【复用】**：原自由聊天框架中的公共模块，雅思场景直接使用，不重新实现。
- **【复用并扩展】**：保留原公共能力，但需要增加雅思事件、参数或返回字段。
- **【雅思替换】**：使用雅思具体实现替换原来的自由聊天具体实现。
- **【雅思新增】**：雅思模拟场景独有的模块。
- **【规划】**：当前 Demo 尚未持久化实现，但正式产品框架建议保留的接口。

## 需要特别区分的五个对象

| 对象 | 表示什么 | 生命周期 |
|---|---|---|
| `IeltsMockSceneSession` | 实时连接和业务会话 | 从开始建连到 WebRTC 会话关闭 |
| `PaperSnapshot` | 本场考试固定使用的试卷 | 组卷后生成，整场考试不可修改 |
| `IeltsExamState` | 当前考试走到哪个阶段 | 每次考试事件发生后更新 |
| `IeltsAttempt` | 一整场考试数据 | 从创建考试到报告生成完成 |
| `IeltsTurn` | 一道题的一轮回答 | 从题目开始回答到该轮回答结束 |
