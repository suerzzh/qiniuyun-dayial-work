# AI 场景会话服务体系——雅思模拟模块伪代码（带注释版）

> 本文以原《自由聊天伪代码》的公共会话抽象为基础，把具体场景从“自由聊天”替换为“IELTS Speaking 模拟考试”。
>
> 阅读目标不是要求直接照抄代码，而是先看懂：**谁负责启动、谁控制考试流程、谁保存回答、谁采集音频、谁触发评分、谁计算最终成绩。**

---

# 一、先看懂几个最重要的概念

## 1. Session：一次实时连接会话

```text
IeltsMockSceneSession
```

它表示用户从“开始考试”到“关闭 WebRTC”这一段实时会话。

主要保存：

```text
localSessionId       // 我们自己系统生成的会话 ID
providerSessionId    // Qwen Realtime 返回的模型会话 ID
userId               // 当前用户
连接状态              // CONNECTING / ACTIVE / COMPLETED / FAILED
attemptId            // 关联的雅思考试记录 ID
examState            // 当前考试进行到哪一步
activeTurnId         // 当前正在回答哪一道题
```

可以理解为：

> Session 主要管理“连接还在不在、实时会话是什么状态”。

---

## 2. Attempt：一整场雅思考试记录

```text
IeltsAttempt
```

它表示一次完整的 IELTS 模考或一次 Part 专项练习。

主要保存：

```text
attemptId
userId
paperSnapshot
所有 Turn
scoringStatus
最终 report
```

可以理解为：

> Attempt 管的是“这一场考试的完整业务记录”。

Session 和 Attempt 通常是一对一，但职责不同：

```text
Session 关注实时连接
Attempt 关注考试数据和评分结果
```

---

## 3. Turn：一道题的一轮回答

```text
IeltsTurn
```

例如 Part 1 有 5 道题，一般就会产生 5 个 Turn。

每个 Turn 保存：

```text
turnId
part
questionId
questionTextSnapshot
rawTranscript
speechChunks
pcmAudio
openedAt
completedAt
completionReason
```

可以理解为：

> Turn 就是“某一道题 + 考生针对这道题的完整回答证据”。

---

## 4. PaperSnapshot：本场考试的冻结试卷

```text
PaperSnapshot
```

考试开始前随机组卷，开始后不再改变。

包含：

```text
Part 1 选中的 Topic 和 4/5 道题
Part 2 完整题卡
与 Part 2 绑定的 Part 3 问题
计时规则
timingProfile
promptVersion
bankVersion
```

为什么要冻结：

```text
防止考试过程中重新随机题目
防止评分时找不到当时真正问过的问题
保证 Part 2 和 Part 3 的话题绑定关系不被破坏
```

---

## 5. ExamState：考试当前进行到哪一步

```text
READY
OPENING
INTRODUCTION
PART1_ANSWERING
PART2_PREPARING
PART2_ANSWERING
PART3_ANSWERING
COMPLETED
ABANDONED
TECHNICAL_INTERRUPTED
```

它的作用是约束合法流程。例如：

```text
当前是 PART1_ANSWERING
就不能直接发送 PART2_SPEAKING_COMPLETED
```

状态机不负责语音识别和评分，只负责：

> 当前能做什么、下一步应该去哪里。

# 二、整体模块结构（带职责注释）

```text
AI 场景会话服务体系
│
├── IeltsMockSessionController
│   ├── 类型：HTTP Controller
│   ├── 作用：接收“开始雅思模拟考试”的 HTTP 请求
│   ├── 输入：考试模式、Part、计时配置、Offer SDP 等
│   └── start(StartIeltsMockCommand) -> StartIeltsMockResult
│       └── [调用] IeltsMockSessionService.start()
│
│       【说明】
│       Controller 只负责接收参数和返回结果，不应该在这里写组卷、
│       状态机或评分逻辑。真正的业务流程放在 Service 中。
│
├── IeltsAttemptController
│   ├── 类型：HTTP Controller
│   ├── 作用：查询或操作一整场考试 Attempt
│   ├── getAttempt()          // 查看当前考试数据
│   ├── finalize()            // 通知后端考试采集结束，开始评分
│   ├── getScoringStatus()    // 查询评分做到哪一步
│   ├── getReport()           // 获取最终报告
│   ├── abandon()             // 用户中途退出
│   └── delete()              // 删除 Attempt
│
│       【说明】
│       实时考试和最终评分耗时不同，所以 Attempt Controller 单独存在。
│       前端结束考试后，可以先得到 FINALIZING，再继续轮询报告。
│
├── SessionWebSocketHandler
│   ├── 类型：WebSocket 事件入口
│   ├── 复用：自由聊天、雅思模拟等 Realtime 场景共用
│   ├── 作用：接收前端同步的 Realtime 事件和用户操作事件
│   │
│   ├── 模型连接事件
│   │   ├── PROVIDER_SESSION_CREATED
│   │   ├── PROVIDER_SESSION_UPDATED
│   │   └── SESSION_ERROR
│   │
│   ├── 语音和转写事件
│   │   ├── USER_SPEECH_STARTED
│   │   ├── USER_SPEECH_STOPPED
│   │   ├── USER_TRANSCRIPT_DELTA
│   │   └── USER_TRANSCRIPT_COMPLETED
│   │
│   ├── 雅思考试事件
│   │   ├── INTRODUCTION_STARTED   # 考官开始自我介绍，确认考生身份
│   │   ├── PART_STARTED         #进入part1
│   │   ├── QUESTION_ASKED       #考官问问题
│   │   ├── TURN_OPENED         #考生回答
│   │   ├── TURN_COMPLETED        #结束回答
│   │   ├── PART2_PREPARATION_EXPIRED
│   │   ├── PART2_SPEAKING_COMPLETED
│   │   ├── PART3_SOFT_LIMIT_REACHED    
│   │   ├── PART3_HARD_LIMIT_REACHED
│   │   └── EXAM_COMPLETED
│   │
│   └── [调用] IeltsMockSessionService.handleEvent()
│
│       【说明】
│       这个 WebSocket 传的是“事件”，例如某个 Turn 开始、某个题目结束。
│       它不是专门传评分 PCM 音频的 WebSocket。
│
├── IeltsScoringWebSocketHandler
│   ├── 类型：评分音频 WebSocket
│   ├── 作用：接收 16 kHz 单声道 PCM 和 Turn 控制事件
│   │
│   ├── Binary Frame
│   │   └── PCM_S16LE / 16000 Hz / mono
│   │
│   ├── Control Event
│   │   ├── STREAM_START       初始化会话、重置状态
│   │   ├── QUESTION_ASKED      标记"等待用户回答"状态
│   │   ├── TURN_OPENED
│   │   ├── TURN_SPEECH_STARTED
│   │   ├── TURN_SPEECH_STOPPED
│   │   ├── TURN_TRANSCRIPT_COMPLETED
│   │   ├── TURN_COMPLETED
│   │   ├── PART2_SPEAKING_COMPLETED
│   │   └── STREAM_END
│   │
│   └── [调用] IeltsTurnAssemblerService
│
│       【说明】
│       浏览器只申请一次麦克风，同一个 MediaStream：
│       一路给 Qwen Realtime，一路转为 PCM 发到这里。
│       这个组件把连续音频按照 Turn 切成每道题的录音片段。
│
├── SessionService
│   ├── 类型：抽象类
│   ├── 复用：所有实时场景共用
│   ├── 作用：提供公共的会话启动和公共事件处理模板
│   │
│   ├── start(StartCommand) -> StartResult
│   │   ├── AuthService 获取当前用户
│   │   ├── ProfileService 获取用户画像
│   │   ├── SessionIdGenerator 生成 localSessionId
│   │   ├── 调用子类 createSession()
│   │   ├── 调用子类 prepareScene()
│   │   ├── UsageQuotaService 校验并预占额度
│   │   ├── SessionStateStore.save(session)
│   │   ├── RealtimeConnectionService 完成 SDP 交换
│   │   ├── session.markConnecting()
│   │   ├── SessionStateStore.save(session)
│   │   └── SessionBindingTimeoutService 启动绑定超时检测
│   │
│   ├── 公共事件处理
│   │   ├── PROVIDER_SESSION_CREATED
│   │   ├── PROVIDER_SESSION_UPDATED
│   │   ├── SESSION_ERROR
│   │   ├── BIND_TIMEOUT
│   │   └── 其他事件交给子类 handleSceneEvent()
│   │
│   └── 子类扩展点
│       ├── createSession()
│       ├── prepareScene()
│       ├── saveTranscript()
│       ├── handleSceneEvent()
│       ├── handleSessionCompleted()
│       └── handleSessionFailed()
│
│       【说明】
│       抽象类只处理所有场景都一样的内容。
│       雅思独有的组卷、Part 切换和评分不能写死在公共 SessionService 中。
│
├── IeltsMockSessionService
│   ├── 类型：雅思具体场景 Service
│   ├── [继承] SessionService
│   ├── 作用：实现 IELTS 独有业务
│   │
│   ├── prepareScene()
│   │   ├── 加载 IELTS 题库
│   │   ├── 生成 PaperSnapshot
│   │   ├── 创建 Attempt
│   │   ├── 创建 ExamState
│   │   └── 生成考官 Prompt
│   │
│   ├── handleSceneEvent()
│   │   ├── 打开 Turn
│   │   ├── 保存 rawTranscript
│   │   ├── 处理 Part 2 Long Turn
│   │   ├── 完成 Turn
│   │   └── 推进 ExamState
│   │
│   └── handleSessionCompleted()
│       ├── 完成音频采集
│       ├── Finalize Attempt
│       ├── 结算额度
│       └── 异步启动评分
│
│       【说明】
│       这是雅思场景最核心的业务 Service。
│       它把公共会话能力、题库、状态机、Turn 和评分编排连接起来。
│
├── IeltsQuestionBankService
│   ├── 作用：加载并校验题库
│   ├── 校验 Part 1 Topic 至少有 4 道可用题
│   ├── 校验 ID 不重复
│   └── 校验 Part 2 和 Part 3 属于同一个 Atomic Bundle
│
│       【说明】
│       它只负责“题库数据是否合法”，不负责本场随机选哪一道题。
│
├── IeltsPaperAssemblerService
│   ├── 作用：从合法题库生成本场 PaperSnapshot
│   ├── Part 1：一个 Topic 内随机抽 4 或 5 题
│   ├── Part 1：抽完后按原始顺序提问
│   ├── Part 2/3：选择同一个 Atomic Bundle
│   └── 最终 deepFreeze()
│
│       【说明】
│       QuestionBankService 管“题库是否正确”，
│       PaperAssemblerService 管“本场具体考什么”。
│
├── IeltsExamFlowService
│   ├── 作用：确定性考试状态机
│   ├── createState()
│   ├── transition()
│   ├── currentExamItem()
│   └── validateQuestionAgainstPaper()
│
│       【说明】
│       大模型不能自行决定跳题或切换 Part。
│       所有流程推进都必须通过状态机事件完成。
│
├── IeltsAttemptService
│   ├── 作用：管理一整场考试记录
│   ├── createAttempt()
│   ├── finalizeCollection()
│   ├── updateScoringStatus()
│   ├── saveReport()
│   └── abandonAttempt()
│
├── IeltsTurnService
│   ├── 作用：管理每一道题的业务回答记录
│   ├── openTurn()
│   ├── speechStarted()
│   ├── speechStopped()
│   ├── appendRawTranscript()
│   ├── completeTurn()
│   └── attachPcmAudio()
│
│       【说明】
│       TurnService 保存的是“回答业务数据”；
│       TurnAssembler 负责“从连续 PCM 中截出这轮音频”。
│
├── IeltsTurnAssemblerService
│   ├── 作用：组装每个 Turn 的 PCM 音频
│   ├── 500 ms pre-roll
│   ├── 700 ms post-roll
│   ├── 5 秒 ring buffer
│   └── Part 2 的 speechStopped 不结束 Long Turn
│
│       【说明】
│       pre-roll 防止句首丢失，post-roll 防止句尾丢失。
│
├── IeltsScoringOrchestrator
│   ├── 类型：异步评分编排器
│   ├── 作用：考试结束后组织所有评分步骤
│   ├── Qwen Language Evidence
│   ├── iFlytek Pronunciation Evidence
│   ├── Local Acoustic Metrics
│   ├── Qwen Holistic Judge
│   ├── Java Band Calculator
│   └── IeltsReport
│
│       【说明】
│       它不一定亲自执行所有算法，而是负责安排调用顺序、并行任务、
│       异常降级和最终报告生成。
│
├── IeltsTextScoringService
│   ├── 第一阶段：FC / LR / GRA 语言证据
│   ├── 第二阶段：综合四维建议分
│   └── 不允许模型直接返回 Overall
│
├── PronunciationEvidenceProvider
│   ├── 实现：XfyunPronunciationEvidenceProvider
│   ├── 输入：Turn PCM + rawTranscript
│   ├── 输出：Accuracy / Fluency / Integrity / 单词错误
│   └── 当前 read_sentence 只标记 LOW confidence
│
│       【说明】
│       讯飞提供的是发音证据，不是 IELTS Pronunciation 最终 Band。
│
├── IeltsAcousticFeatureService
│   ├── 回答时长
│   ├── 实际说话时长
│   ├── 沉默比例
│   ├── 语速
│   ├── 停顿和长停顿
│   ├── filler 数量
│   └── Part 2 最长连续说话时长
│
│       【说明】
│       这里主要使用时间戳、VAD chunk 和转写进行客观计算，
│       不是直接用大模型凭感觉估算。
│
├── IeltsBandCalculator
│   ├── 校验每项 Band 在 0～9 之间
│   ├── 校验必须是 0.5 步长
│   ├── 四项等权平均
│   └── 缺任何一项则 Overall 为 null
│
└── IeltsReportService
    ├── COMPLETE Report
    ├── PARTIAL Report
    └── UNSCORABLE Report
```

# 三、启动考试伪代码（逐步注释版）

```java
@Service
public class IeltsMockSessionService extends SessionService {

    public StartIeltsMockResult start(
            StartIeltsMockCommand command) {

        // ====================================================
        // 第 1 步：识别是谁在使用系统
        // ====================================================

        String userId =
            AuthService.getCurrentUserId();

        // 【说明】
        // 从登录态获取用户 ID。
        // 后续额度、历史题目、学习记录都需要绑定 userId。

        UserProfile profile =
            ProfileService.getProfile(userId);

        // 【说明】
        // 获取用户配置，例如偏好音色、学习等级等。
        // IELTS 的正式题目不应该根据画像随意改写，
        // 画像主要用于音色或允许的辅助配置。


        // ====================================================
        // 第 2 步：检查用户能不能使用 IELTS 场景
        // ====================================================

        SceneConfig sceneConfig =
            SceneService.getByType(
                SceneType.IELTS_MOCK
            );

        SceneService.validateAccess(
            userId,
            sceneConfig
        );

        // 【说明】
        // 例如判断场景是否开放、会员等级是否允许使用。

        UsageQuotaService.validate(
            userId,
            SceneType.IELTS_MOCK
        );

        // 【说明】
        // 只做“是否有足够额度”的校验，
        // 真正预占额度在会话创建完成后执行。


        // ====================================================
        // 第 3 步：加载并校验题库
        // ====================================================

        IeltsQuestionBank questionBank =
            IeltsQuestionBankService.loadQuestionBank(
                command.getBankVersion()
            );

        // 【说明】
        // 这里加载的是完整合法题库，不是本场试卷。
        // 服务内部还会检查 Topic、题目 ID 和 P2/P3 绑定关系。


        // ====================================================
        // 第 4 步：为本场考试组卷
        // ====================================================

        PaperSnapshot paperSnapshot =
            IeltsPaperAssemblerService.assemble(
                AssemblePaperCommand.builder()
                    .setQuestionBank(questionBank)
                    .setMode(command.getMode())
                    .setSelectedPart(
                        command.getSelectedPart()
                    )
                    .setTimingProfile(
                        command.getTimingProfile()
                    )
                    .setRecentQuestionIds(
                        IeltsLearningRecordService
                            .getRecentQuestionIds(userId)
                    )
                    .build()
            );

        // 【说明】
        // command.getMode()：完整模考或专项练习。
        // command.getSelectedPart()：专项练习时选择 P1/P2/P3。
        // recentQuestionIds：尽量避免用户最近刚做过的题。
        // 返回的 PaperSnapshot 会冻结，考试中不能换题。


        // ====================================================
        // 第 5 步：创建实时会话 Session
        // ====================================================

        String localSessionId =
            SessionIdGenerator.generate();

        IeltsMockSceneSession session =
            new IeltsMockSceneSession(
                localSessionId,
                userId
            );

        // 【说明】
        // localSessionId 是我们系统自己的会话 ID。
        // 即使 Qwen providerSessionId 还没返回，
        // 我们也能先用 localSessionId 保存状态和关联前端。


        // ====================================================
        // 第 6 步：创建考试 Attempt
        // ====================================================

        IeltsAttempt attempt =
            IeltsAttemptService.createAttempt(
                CreateAttemptCommand.builder()
                    .setUserId(userId)
                    .setLocalSessionId(localSessionId)
                    .setMode(command.getMode())
                    .setPaperSnapshot(paperSnapshot)
                    .build()
            );

        // 【说明】
        // Attempt 是整场考试记录。
        // 之后所有 Turn、音频、转写和报告都归到这个 attemptId 下。


        // ====================================================
        // 第 7 步：创建考试状态机
        // ====================================================

        IeltsExamState examState =
            IeltsExamFlowService.createState(
                paperSnapshot,
                SessionPolicy.builder()
                    .setCaptionsEnabled(
                        command.isCaptionsEnabled()
                    )
                    .setRecordingEnabled(
                        command.isRecordingEnabled()
                    )
                    .setStrictMock(
                        command.getMode()
                            == IeltsMode.FULL_MOCK
                    )
                    .build()
            );

        // 【说明】
        // full_mock 使用严格模式，不允许随意跳题或重试。
        // practice_part 可以允许更多练习操作。
        // 初始状态一般为 READY，等 Realtime 配置完成后再 START。


        // ====================================================
        // 第 8 步：生成 Realtime 考官 Prompt
        // ====================================================

        SessionPrompt examinerPrompt =
            IeltsExaminerPromptService.build(
                profile,
                sceneConfig,
                paperSnapshot
            );

        // 【说明】
        // Prompt 主要约束模型：
        // 1. 只做考官，不教学；
        // 2. 不自行选题；
        // 3. 不自行切换 Part；
        // 4. 只朗读状态机给出的固定指令和题目。


        // ====================================================
        // 第 9 步：把 IELTS 数据装入 Session
        // ====================================================

        session.setSceneId(
            sceneConfig.getSceneId()
        );

        session.setProviderType(
            sceneConfig.getProviderType()
        );

        session.setPrompt(examinerPrompt);
        session.setAttemptId(attempt.getAttemptId());
        session.setExamMode(command.getMode());
        session.setPaperSnapshot(paperSnapshot);
        session.setExamState(examState);
        session.setTimingProfile(
            paperSnapshot.getTimingProfile()
        );

        // 【说明】
        // Session 中只保存当前运行所需的引用和状态，
        // 完整考试历史仍由 Attempt 和 Turn 保存。


        // ====================================================
        // 第 10 步：预占额度并保存初始状态
        // ====================================================

        UsageQuotaService.reserve(
            userId,
            localSessionId,
            SceneType.IELTS_MOCK
        );

        SessionStateStore.save(session);
        IeltsAttemptService.save(attempt);

        // 【说明】
        // reserve 表示先冻结一部分可用额度，
        // 防止用户在会话进行中把额度用于其他场景。


        try {

            // ================================================
            // 第 11 步：由后端代理完成 SDP 交换
            // ================================================

            String answerSdp =
                RealtimeConnectionService
                    .createAnswerSdp(
                        session.getProviderType(),
                        command.getOfferSdp(),
                        examinerPrompt
                    );

            // 【说明】
            // 前端发送 Offer SDP。
            // 后端使用服务端凭据调用 Qwen Realtime，获得 Answer SDP。
            // API Key 不暴露给浏览器或移动端。


            // ================================================
            // 第 12 步：进入等待模型绑定状态
            // ================================================

            session.markConnecting();
            SessionStateStore.save(session);

            SessionBindingTimeoutService.schedule(
                localSessionId,
                BIND_TIMEOUT
            );

            // 【说明】
            // SDP 成功不代表 Qwen DataChannel 一定已经返回 session.created。
            // 所以要启动超时检测，避免会话一直卡在 CONNECTING。


            // ================================================
            // 第 13 步：把建连和考试信息返回给前端
            // ================================================

            return StartIeltsMockResult.builder()
                .setLocalSessionId(localSessionId)
                .setAttemptId(attempt.getAttemptId())
                .setAnswerSdp(answerSdp)
                .setScoringWebSocketUrl(
                    "/api/ielts/scoring-stream"
                    + "?attempt_id="
                    + attempt.getAttemptId()
                )
                .setPaperSnapshot(paperSnapshot)
                .setInitialExamState(examState)
                .setScoringStatus(
                    IeltsScoringStatus.COLLECTING
                )
                .build();

            // 【说明】
            // 前端拿到：
            // 1. Answer SDP，用于建立 Qwen WebRTC；
            // 2. scoringWebSocketUrl，用于发送 PCM；
            // 3. PaperSnapshot，用于展示题卡和题目；
            // 4. AttemptId，用于后续 Finalize 和查询报告。

        } catch (Exception exception) {

            session.fail(
                "IELTS_SESSION_START_FAILED",
                exception.getMessage()
            );

            SessionStateStore.save(session);

            IeltsAttemptService
                .markTechnicalInterrupted(
                    attempt.getAttemptId(),
                    exception.getMessage()
                );

            UsageQuotaService.release(
                localSessionId
            );

            throw exception;

            // 【说明】
            // 启动失败时必须同时处理：
            // Session 状态、Attempt 状态、已预占额度。
        }
    }
}
```

# 四、考试事件处理伪代码（带注释版）

```java
public void handleEvent(
        String localSessionId,
        SessionEvent event) {

    IeltsMockSceneSession session =
        SessionStateStore.get(localSessionId);

    // 【说明】
    // WebSocket 事件本身只带 localSessionId 和 event。
    // 需要先从 Store 取出完整 Session，才能知道当前 Attempt、Part 和 Turn。

    switch (event.getType()) {

        case PROVIDER_SESSION_CREATED -> {

            session.bindProviderSession(
                event.getProviderSessionId()
            );

            SessionBindingTimeoutService.cancel(
                localSessionId
            );

            UsageQuotaService.startMetering(
                localSessionId
            );

            SessionStateStore.save(session);

            // 【说明】
            // Qwen 返回 session.created 后，说明模型会话已真正建立。
            // 这时取消超时任务，并开始实际计费。
        }


        case PROVIDER_SESSION_UPDATED -> {

            session.activate();

            session.setExamState(
                IeltsExamFlowService.transition(
                    session.getExamState(),
                    IeltsExamEvent.START
                )
            );

            SessionStateStore.save(session);

            SessionWebSocketHandler.sendExamCommand(
                localSessionId,
                ExaminerCommand.playOpening()
            );

            // 【说明】
            // session.updated 表示 Prompt、ASR、VAD 等配置已经生效。
            // 只有此时才正式启动状态机并播放开场白，避免配置竞态。
        }


        case INTRODUCTION_STARTED -> {

            IeltsTurn introTurn =
                IeltsTurnService.openTurn(
                    OpenTurnCommand.builder()
                        .setAttemptId(
                            session.getAttemptId()
                        )
                        .setPart(0)
                        .setQuestionId("introduction")
                        .setQuestionText(
                            "Please introduce yourself."
                        )
                        .setTurnType(
                            TurnType.INTRODUCTION
                        )
                        .setScoringEligible(false)
                        .build()
                );

            session.setActiveTurnId(
                introTurn.getTurnId()
            );

            SessionStateStore.save(session);

            // 【说明】
            // 自我介绍仍然保存音频和转写，用于完整考试记录，
            // 但 scoringEligible=false，因此不会进入 Band 评分。
        }


        case PART_STARTED -> {

            IeltsExamFlowService.validatePart(
                session.getExamState(),
                event.getPart()
            );

            session.setCurrentPart(
                event.getPart()
            );

            IeltsAttemptService.updateCurrentPart(
                session.getAttemptId(),
                event.getPart()
            );

            SessionStateStore.save(session);

            // 【说明】
            // 先用状态机校验当前能否进入这个 Part，
            // 再更新 Session 和 Attempt，不能只相信前端传来的 Part。
        }


        case QUESTION_ASKED -> {

            IeltsExamFlowService
                .validateQuestionAgainstPaper(
                    session.getPaperSnapshot(),
                    event.getPart(),
                    event.getQuestionId(),
                    event.getQuestionText()
                );

            session.setCurrentQuestionId(
                event.getQuestionId()
            );

            IeltsAttemptService
                .updateCurrentQuestion(
                    session.getAttemptId(),
                    event.getQuestionId(),
                    event.getQuestionText()
                );

            SessionStateStore.save(session);

            // 【说明】
            // 这一步防止前端或模型临时编造题目。
            // questionId 和 questionText 必须与冻结 PaperSnapshot 一致。
        }


        case TURN_OPENED -> {

            IeltsTurn turn =
                IeltsTurnService.openTurn(
                    OpenTurnCommand.builder()
                        .setAttemptId(
                            session.getAttemptId()
                        )
                        .setPart(event.getPart())
                        .setQuestionId(
                            event.getQuestionId()
                        )
                        .setQuestionText(
                            event.getQuestionText()
                        )
                        .setTurnType(
                            event.getTurnType()
                        )
                        .setScoringEligible(
                            event.getPart() >= 1
                            && event.getPart() <= 3
                        )
                        .build()
                );

            IeltsTurnAssemblerService.openTurn(
                turn.getTurnId(),
                event.getPart(),
                event.getQuestionText(),
                event.getTurnType()
            );

            session.setActiveTurnId(
                turn.getTurnId()
            );

            SessionStateStore.save(session);

            // 【说明】
            // TurnService 创建业务记录；
            // TurnAssembler 同时开始从连续 PCM 流截取该 Turn 音频。
        }


        case USER_SPEECH_STARTED -> {

            String turnId =
                session.getActiveTurnId();

            IeltsTurnService.speechStarted(
                turnId,
                event.getTimestampMs()
            );

            IeltsTurnAssemblerService.speechStarted(
                turnId,
                event.getTimestampMs()
            );

            // 【说明】
            // 这是 Qwen VAD 检测到开始说话。
            // 用于建立 speech chunk 和后续计算说话时长、响应延迟。
        }


        case USER_SPEECH_STOPPED -> {

            String turnId =
                session.getActiveTurnId();

            IeltsTurnService.speechStopped(
                turnId,
                event.getTimestampMs()
            );

            IeltsTurnAssemblerService.speechStopped(
                turnId,
                event.getTimestampMs()
            );

            // 【重要说明】
            // speechStopped 只代表考生出现一次停顿。
            // 对 Part 2 来说，它绝对不能直接完成整个回答。
            // Part 2 只有以下情况才完成：
            // 1. 用户点击“结束本轮回答”；
            // 2. 达到 2 分钟时间限制；
            // 3. 考试状态明确切换。
        }


        case USER_TRANSCRIPT_COMPLETED -> {

            String turnId =
                session.getActiveTurnId();

            IeltsTurnService.appendRawTranscript(
                AppendTranscriptCommand.builder()
                    .setTurnId(turnId)
                    .setRawTranscript(
                        event.getTranscript()
                    )
                    .build()
            );

            // 【说明】
            // 保存的是 Qwen Realtime 原始转写。
            // 不允许先纠正语法、润色后再作为评分输入。
        }


        case TURN_COMPLETED -> {

            completeCurrentTurn(
                session,
                event.getCompletionReason()
            );

            advanceExamState(
                session,
                IeltsExamEvent.SUBMIT_ANSWER
            );

            // 【说明】
            // 普通 Part 1 / Part 3 回答结束：
            // 先完成 Turn，再让状态机进入下一题或下一 Part。
        }


        case PART2_SPEAKING_COMPLETED -> {

            completeCurrentTurn(
                session,
                event.getCompletionReason()
            );

            advanceExamState(
                session,
                IeltsExamEvent.SUBMIT_ANSWER
            );

            // 【说明】
            // 这是 Part 2 Long Turn 唯一的主要显式结束事件。
        }


        case PART2_PREPARATION_EXPIRED -> {

            advanceExamState(
                session,
                IeltsExamEvent.PREP_EXPIRED
            );

            // 【说明】
            // 准备倒计时结束，笔记锁定，状态进入 PART2_ANSWERING。
        }


        case PART3_SOFT_LIMIT_REACHED -> {

            advanceExamState(
                session,
                IeltsExamEvent.PART3_SOFT_LIMIT
            );

            // 【说明】
            // 达到软限制后不一定立即打断正在说话的考生，
            // 一般在当前题结束后完成 Part 3。
        }


        case PART3_HARD_LIMIT_REACHED -> {

            if (session.getActiveTurnId() != null) {
                completeCurrentTurn(
                    session,
                    CompletionReason.TIME_LIMIT
                );
            }

            advanceExamState(
                session,
                IeltsExamEvent.PART3_HARD_LIMIT
            );

            handleSessionCompleted(
                localSessionId
            );

            // 【说明】
            // 硬限制必须强制结束当前回答并结束考试。
        }


        case EXAM_COMPLETED,
             SESSION_COMPLETE -> {

            session.complete();
            SessionStateStore.save(session);

            handleSessionCompleted(
                localSessionId
            );

            // 【说明】
            // 这里结束的是“实时考试采集阶段”，
            // 评分报告不会同步在此处完成。
        }


        case EXAM_ABANDON -> {

            session.abandon();
            SessionStateStore.save(session);

            IeltsAttemptService.abandonAttempt(
                session.getAttemptId()
            );

            IeltsTurnAssemblerService.finishStream(
                session.getAttemptId()
            );

            UsageQuotaService.settle(
                localSessionId
            );

            // 【说明】
            // 用户中途退出时一般不生成完整 Overall，
            // 但可以保留已经采集的 Turn 作为未完成记录。
        }


        case SESSION_ERROR -> {

            session.fail(
                event.getErrorCode(),
                event.getErrorMessage()
            );

            SessionStateStore.save(session);

            IeltsAttemptService
                .markTechnicalInterrupted(
                    session.getAttemptId(),
                    event.getErrorMessage()
                );

            IeltsTurnAssemblerService.finishStream(
                session.getAttemptId()
            );

            UsageQuotaService.settle(
                localSessionId
            );

            // 【说明】
            // 模型、WebRTC、WebSocket 或状态机异常都进入技术中断。
            // 已采集的数据仍应尽量保存。
        }


        case BIND_TIMEOUT -> {

            if (session.getProviderSessionId() == null) {

                session.fail(
                    "PROVIDER_BIND_TIMEOUT",
                    "Qwen Realtime 会话绑定超时"
                );

                SessionStateStore.save(session);

                UsageQuotaService
                    .settleReservedQuota(
                        localSessionId
                    );

                SessionWebSocketHandler
                    .sendCloseWebRtc(
                        localSessionId
                    );
            }

            // 【说明】
            // SDP 已返回，但规定时间内没收到 providerSessionId，
            // 说明连接没有完整建立，需要关闭并回滚预占额度。
        }
    }
}
```

```java
private void completeCurrentTurn(
        IeltsMockSceneSession session,
        CompletionReason reason) {

    String turnId =
        session.getActiveTurnId();

    if (turnId == null) {
        return;
    }

    // 【说明】
    // 没有 activeTurnId，说明当前没有正在回答的题目，
    // 直接返回，避免重复完成同一个 Turn。

    long completedAt =
        System.currentTimeMillis();

    IeltsTurnService.completeTurn(
        CompleteTurnCommand.builder()
            .setTurnId(turnId)
            .setCompletedAtMs(completedAt)
            .setReason(reason)
            .build()
    );

    // 【说明】
    // 更新业务 Turn：完成时间、完成原因、状态。

    IeltsTurnAssemblerService.completeTurn(
        turnId,
        completedAt,
        reason
    );

    // 【说明】
    // 通知音频组装器准备结束该 Turn。
    // 它仍会继续收集约 700 ms post-roll，防止句尾丢失。

    session.clearActiveTurnId();
    SessionStateStore.save(session);
}
```

# 六、考试结束后的异步评分触发

```java
protected void handleSessionCompleted(
        String localSessionId) {

    IeltsMockSceneSession session =
        SessionStateStore.get(localSessionId);

    String attemptId =
        session.getAttemptId();


    // 第 1 步：结束 PCM 流并冻结音频
    IeltsTurnAssemblerService.finishStream(
        attemptId
    );

    // 【说明】
    // 把尚未冻结的 post-roll 音频收尾，
    // 保证每个 Turn 的 PCM 可以交给讯飞评分。


    // 第 2 步：Attempt 进入 FINALIZING
    IeltsAttemptService.finalizeCollection(
        attemptId
    );

    // 【说明】
    // FINALIZING 表示考试已经结束，正在整理评分输入。


    // 第 3 步：结算实时会话额度
    UsageQuotaService.settle(
        localSessionId
    );

    // 【说明】
    // Realtime 通话已结束，可以结算语音会话额度。
    // 评分模型用量也可以在评分服务内部另行记录。


    // 第 4 步：异步启动评分
    IeltsScoringOrchestrator
        .scoreAsync(attemptId)
        .thenAccept(report -> {

            IeltsAttemptService.saveReport(
                attemptId,
                report
            );

            IeltsLearningRecordService
                .saveAttemptSummary(
                    attemptId,
                    session.getUserId()
                );

            SessionWebSocketHandler
                .sendReportReady(
                    localSessionId,
                    attemptId,
                    report.getScoringStatus()
                );
        })
        .exceptionally(error -> {

            IeltsAttemptService
                .markScoringFailed(
                    attemptId,
                    error.getMessage()
                );

            SessionWebSocketHandler
                .sendScoringError(
                    localSessionId,
                    attemptId,
                    error.getMessage()
                );

            return null;
        });

    // 【重要说明】
    // scoreAsync() 返回 CompletableFuture，
    // 所以不会阻塞“考试结束”请求。
    // 前端可以立即展示“正在生成报告”，然后轮询或等待 REPORT_READY。
}
```

# 七、异步评分内部流程（逐步注释版）

```java
@Service
public class IeltsScoringOrchestrator {

    public CompletableFuture<IeltsReport> scoreAsync(
            String attemptId) {

        IeltsAttempt attempt =
            IeltsAttemptService.getAttempt(
                attemptId
            );

        IeltsAttemptService.updateScoringStatus(
            attemptId,
            IeltsScoringStatus.SCORING
        );

        // 【说明】
        // FINALIZING 结束后进入 SCORING。


        // ====================================================
        // 第 1 步：只筛选真正参与评分的 Turn
        // ====================================================

        List<IeltsTurn> scoringTurns =
            attempt.getTurns().stream()
                .filter(IeltsTurn::isScoringEligible)
                .filter(turn ->
                    turn.getPart() >= 1
                    && turn.getPart() <= 3
                )
                .toList();

        // 【说明】
        // Introduction 的 scoringEligible=false，因此不会参与评分。


        // ====================================================
        // 第 2 步：没有有效回答则直接 UNSCORABLE
        // ====================================================

        if (scoringTurns.isEmpty()
                || scoringTurns.stream()
                    .noneMatch(turn ->
                        !turn.getRawTranscript().isBlank()
                    )) {

            IeltsReport report =
                IeltsReportService
                    .buildUnscorableReport(
                        attempt,
                        "没有有效 raw transcript"
                    );

            return CompletableFuture
                .completedFuture(report);
        }

        // 【说明】
        // 没有有效转写时不浪费模型调用额度，也不能凭空评分。


        // ====================================================
        // 第 3 步：计算本地客观指标
        // ====================================================

        List<TurnScoringInput> turnInputs =
            scoringTurns.stream()
                .map(turn ->
                    TurnScoringInput.builder()
                        .setTurn(turn)
                        .setMetrics(
                            IeltsAcousticFeatureService
                                .calculate(turn)
                        )
                        .build()
                )
                .toList();

        // 【说明】
        // 这些 metrics 包括：语速、停顿、沉默比例、回答时长等。
        // 它们主要帮助判断 FC，不直接等于最终 Band。


        // ====================================================
        // 第 4 步：启动千问语言评分异步任务
        // ====================================================

        CompletableFuture<LanguageEvidence>
            languageFuture =
                IeltsTextScoringService
                    .languageEvidence(
                        ScoringInput.from(
                            attempt,
                            turnInputs
                        )
                    );

        // 【说明】
        // 千问第一阶段主要输出：
        // FC、LR、GRA 的结构化语言证据。


        // ====================================================
        // 第 5 步：并行调用每个 Turn 的讯飞发音评测
        // ====================================================

        List<CompletableFuture<PronunciationEvidence>>
            pronunciationFutures =
                scoringTurns.stream()
                    .map(turn ->
                        PronunciationEvidenceProvider
                            .evaluate(turn)
                            .orTimeout(
                                60,
                                TimeUnit.SECONDS
                            )
                            .exceptionally(error ->
                                PronunciationEvidence
                                    .failure(
                                        error.getMessage()
                                    )
                            )
                    )
                    .toList();

        // 【说明】
        // 每个 Turn 都可以独立调用讯飞，因此可以并行。
        // 某一道题失败不会直接让整场评分崩溃，而是记录 failure evidence。

        CompletableFuture<Void>
            allPronunciationFuture =
                CompletableFuture.allOf(
                    pronunciationFutures.toArray(
                        CompletableFuture[]::new
                    )
                );


        // ====================================================
        // 第 6 步：等待语言证据和所有发音证据完成
        // ====================================================

        return languageFuture
            .thenCombine(
                allPronunciationFuture,
                (languageEvidence, ignored) -> {

                    List<PronunciationEvidence>
                        pronunciationEvidence =
                            pronunciationFutures.stream()
                                .map(
                                    CompletableFuture::join
                                )
                                .toList();

                    return HolisticJudgeInput.builder()
                        .setAttempt(attempt)
                        .setTurnInputs(turnInputs)
                        .setLanguageEvidence(
                            languageEvidence
                        )
                        .setPronunciationEvidence(
                            pronunciationEvidence
                        )
                        .setDataQualityWarnings(
                            DataQualityPolicy.collect(
                                turnInputs,
                                pronunciationEvidence
                            )
                        )
                        .build();
                }
            )

            // 【说明】
            // thenCombine 表示：
            // languageFuture 和 allPronunciationFuture 都完成后，
            // 才构造综合 Judge 输入。


            // =================================================
            // 第 7 步：调用千问综合 Judge
            // =================================================

            .thenCompose(
                IeltsTextScoringService::holisticJudge
            )

            // 【说明】
            // Holistic Judge 综合：
            // raw transcript、语言证据、讯飞证据、客观指标和数据质量警告，
            // 输出 FC / LR / GRA / Pronunciation 四维建议分。


            // =================================================
            // 第 8 步：Java 校验四维分数并计算 Overall
            // =================================================

            .thenApply(judgeResult -> {

                DimensionResult fc =
                    validateDimension(
                        "FC",
                        judgeResult
                            .getFluencyCoherence()
                    );

                DimensionResult lr =
                    validateDimension(
                        "LR",
                        judgeResult
                            .getLexicalResource()
                    );

                DimensionResult gra =
                    validateDimension(
                        "GRA",
                        judgeResult
                            .getGrammaticalRangeAccuracy()
                    );

                DimensionResult pronunciation =
                    validateDimension(
                        "Pronunciation",
                        judgeResult
                            .getPronunciation()
                    );

                // 【说明】
                // 模型可能返回非法值，例如 6.3 或 9.5。
                // Java 必须校验，只接受 0～9 且以 0.5 为步长的分数。

                BandResult bandResult =
                    IeltsBandCalculator.calculate(
                        fc.getBand(),
                        lr.getBand(),
                        gra.getBand(),
                        pronunciation.getBand()
                    );

                // 【说明】
                // Overall 由 Java 固定公式计算：
                // (FC + LR + GRA + Pronunciation) / 4，
                // 再取最近的 0.5。
                // 任一维度为空，Overall 也为空。


                IeltsReport report =
                    bandResult.getOverallBand() == null
                        ? IeltsReportService
                            .buildPartialReport(
                                attempt,
                                judgeResult,
                                bandResult
                            )
                        : IeltsReportService
                            .buildCompleteReport(
                                attempt,
                                judgeResult,
                                bandResult
                            );

                IeltsAttemptService.saveReport(
                    attemptId,
                    report
                );

                return report;
            })


            // =================================================
            // 第 9 步：处理整个评分流水线异常
            // =================================================

            .exceptionally(error -> {

                IeltsReport report =
                    IeltsReportService
                        .buildUnscorableReport(
                            attempt,
                            error.getMessage()
                        );

                IeltsAttemptService.saveReport(
                    attemptId,
                    report
                );

                return report;
            });
    }
}
```

# 八、Part 2 Long Turn 为什么要单独处理

## 普通 Part 1 / Part 3

```text
TURN_OPENED
→ speech_started
→ speech_stopped
→ 用户结束回答
→ TURN_COMPLETED
```

## Part 2

```text
TURN_OPENED(PART2_LONG_TURN)
→ speech_started
→ speech_stopped      // 一次停顿，只关闭一个 chunk
→ speech_started
→ speech_stopped      // 仍然不结束整个回答
→ 用户明确结束或时间到
→ PART2_SPEAKING_COMPLETED
```

关键规则：

```java
case USER_SPEECH_STOPPED -> {
    IeltsTurnService.speechStopped(...);
    IeltsTurnAssemblerService.speechStopped(...);

    // 不调用 completeCurrentTurn()
}
```

> 这样才能避免考生正常思考停顿时，被 VAD 提前结束两分钟长回答。

# 十二、最简化的一段伪代码

如果前面的代码仍然较复杂，可以先只记住这一层：

```text
FUNCTION startIeltsExam(userRequest):

    user = getCurrentUser()
    validatePermissionAndQuota(user)

    questionBank = loadQuestionBank()
    paper = assembleAndFreezePaper(questionBank, userRequest)

    session = createRealtimeSession(user)
    attempt = createIeltsAttempt(user, paper)
    examState = createExamState(paper)

    connectQwenRealtime(session)
    connectPcmScoringStream(attempt)

    WHILE examState is not completed:
        question = getCurrentQuestion(examState, paper)
        examinerSpeak(question)

        turn = openTurn(question)
        collectRawTranscript(turn)
        collectPcmAudio(turn)

        WHEN user explicitly finishes OR time expires:
            completeTurn(turn)
            examState = moveToNextState(examState)

    finalizeAttempt(attempt)

    ASYNC:
        languageEvidence = qwenScoreRawTranscript()
        pronunciationEvidence = xfyunScorePcmAudio()
        metrics = calculateLocalFluencyMetrics()

        fourDimensions = qwenHolisticJudge(
            languageEvidence,
            pronunciationEvidence,
            metrics
        )

        overall = javaCalculateOverall(fourDimensions)
        report = buildIeltsReport(fourDimensions, overall)
        saveAndPublishReport(report)
```

一句话理解：

> 公共 Session 架构负责连接、鉴权和额度；IELTS 场景层负责组卷和考试状态；Turn 层负责保存每道题的音频与转写；评分编排器在考试结束后异步生成四维报告。
